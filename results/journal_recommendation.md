# 投稿先候補の提案

## 一般変数由来の層別化によるコヒーレント集団の抽出と疑似ランダム化の検証

---

## 研究の特性（投稿先選定の判断基準）

本研究は以下の特性を持つ：

| 特性 | 内容 |
|------|------|
| 研究タイプ | シミュレーション研究（方法論開発） |
| 主題 | 観察研究における未測定交絡への対処、層別化手法の開発 |
| 新規性 | コヒーレント集団の概念導入、コヒーレンス度指標（C1等）の提案 |
| 手法 | 決定力ベース・特徴量得点ベースの層別化、PCA、クラスタリング、ML |
| 分野横断性 | 生物統計学 × 疫学 × 機械学習 |
| 現段階 | Proof of concept（シミュレーションのみ、実データ検証は未実施） |

## 推奨順位

### 第1候補：Statistics in Medicine（Wiley）

| 項目 | 内容 |
|------|------|
| IF | 1.6-2.0（2024） |
| 分野 | 医学統計学全般 |
| ISSN | 0277-6715（Print）/ 1097-0258（Online） |
| 査読 | あり |
| OA | ハイブリッド（OAオプションあり） |
| 掲載料 | OA選択時 $3,900 USD程度 |
| URL | https://onlinelibrary.wiley.com/journal/10970258 |

**推奨理由：**
1. **最もフィットする対象読者層**。医学統計の手法開発論文を主軸とするジャーナルであり、シミュレーション研究が投稿の主要形態の一つ。
2. **類似論文の掲載実績が豊富**。傾向スコア、予後スコア、hdPSに関するシミュレーション研究が多数掲載されており、レビュアーが本研究のコンテキストを理解しやすい。
3. **シミュレーション単独の論文が受理されやすい**。実データ検証がなくても、方法論の原理的検証として十分に評価される。
4. 未測定交絡に関する方法論的議論が活発（Varga et al. 2022のスコーピングレビュー等）。

**フレーミングの提案：**
- タイトル例："Detecting unmeasured population substructure through outcome-prediction residuals: A simulation study of coherent population extraction"
- 「コヒーレント集団」概念を統計的均質性の文脈で導入し、C1指標をI²統計量の拡張として位置づける。

**注意点：**
- IFは高くないが、生物統計分野では標準的な投稿先として高く評価されている（h-index 229）。
- 論文は比較的長い原著も受理される（制限なし）。

### 第2候補：BMC Medical Research Methodology（Springer Nature）

| 項目 | 内容 |
|------|------|
| IF | 3.4（2024）/ 5年IF: 5.2 |
| 分野 | 医学研究方法論 |
| ISSN | 1471-2288（Online） |
| 査読 | あり |
| OA | 完全OA |
| 掲載料 | $2,490 EUR / $2,890 USD |
| URL | https://bmcmedresmethodol.biomedcentral.com/ |

**推奨理由：**
1. **完全OAでアクセシビリティが高い**。研究のインパクトを最大化しやすい。
2. **"Causal inference and observational data vol. 2" のCall for Papers（締切: 2026年7月30日）に該当**。本研究のテーマと直接合致する特集号が現在投稿募集中であり、タイミングが非常に良い。
3. 疫学研究方法論（epidemiological research methodology）を明示的にスコープに含む。
4. IFはStatistics in Medicineより高く、引用されやすい。
5. 初回判定までの中央値が7日と極めて速い。

**フレーミングの提案：**
- タイトル例："Stratification by prediction residuals to extract coherent subpopulations in observational studies: A simulation-based evaluation"
- 「コヒーレンス度指標」をTable 1の均質性検証の補完ツールとして位置づけ、臨床疫学研究者にとっての実用的価値を強調する。

**注意点：**
- 特集号への投稿は通常のプロセスより受理率が高い傾向がある。
- BMC系列は方法論の「科学的手法そのもの」ではなく「方法論的アプローチ」を求めるため、臨床的文脈での意義を十分に論じる必要がある。

### 第3候補：American Journal of Epidemiology（Oxford University Press）

| 項目 | 内容 |
|------|------|
| IF | 5.0-6.0（推定、2024） |
| 分野 | 疫学全般（方法論含む） |
| ISSN | 0002-9262（Print）/ 1476-6256（Online） |
| 査読 | あり |
| OA | ハイブリッド |
| URL | https://academic.oup.com/aje |

**推奨理由：**
1. **"Practice of Epidemiology" セクション**に方法論的シミュレーション研究を掲載。未測定交絡への感度分析に関する論文が多数。
2. IFが高く、疫学分野での可視性が最大。
3. 未測定交絡に関するシステマティックレビュー（Latour et al. 2024）を掲載しており、本研究のコンテキストに合致。

**フレーミングの提案：**
- Practice of Epidemiologyセクションに投稿。
- 「未測定交絡への新たなアプローチ」として、既存手法（PS, hdPS, 予後スコア）との理論的比較を前面に出す。
- コヒーレント集団の概念は生態学的誤謬の回避策として位置づける。

**注意点：**
- 競争率が高い（受理率は低い）。
- 実データ検証がないことがマイナスに働く可能性あり。投稿前にpilot的な実データ応用を追加することを検討すべき。

| 掲載料 | OA選択時 £3,260 GBP程度 |
| URL | https://academic.oup.com/ije |

**推奨理由：**
1. IFが高く、疫学分野で最も影響力のあるジャーナルの一つ。
2. 「新しい方法」（new methods）を明示的にスコープに含む。
3. 方法論的Tutorial論文も掲載しており、教育的要素を含む手法論文を歓迎。

**フレーミングの提案：**
- 「集団の均質性を事後的に評価する新指標」として、STRATOS initiative（観察研究の分析ガイダンス）との関連で位置づける。

**注意点：**
- AJEと同様、シミュレーション単独では受理されにくい可能性がある。
- 方法論のみの論文より、実データ応用を含む論文が好まれる傾向。

### 第5候補：Epidemiology（Lippincott Williams & Wilkins）

| 項目 | 内容 |
|------|------|
| IF | 4.7-5.0（推定） |
| 分野 | 疫学全般 |
| ISSN | 1044-3983（Print）/ 1531-5487（Online） |
| 査読 | あり |
| OA | ハイブリッド |
| URL | https://journals.lww.com/epidem/ |

**推奨理由：**
1. **"Methods" セクション**が充実。因果推論手法に関するシミュレーション論文（Causal Roadmap, Nance et al. 2024等）を活発に掲載。
2. 方法論的議論を重視する編集方針。
3. 簡潔かつインパクトのある短い論文を好む傾向があり、proof of concept段階の論文にも対応。

**フレーミングの提案：**
- 短い原著（3,500語程度）として、コヒーレンス度指標C1に焦点を絞った論文を構成。
- 「全ての観察研究が持つべき均質性評価ステップ」という実用的メッセージを前面に出す。

**注意点：**
- 短い論文が好まれるため、全手法の詳細比較よりも核心的な発見に絞る必要がある。

## 戦略的投稿プラン

### 推奨戦略

```
Phase 1（現在のシミュレーション結果で投稿可能）
  ├── 第1選択: BMC Medical Research Methodology
  │     理由: 特集号 "Causal inference and observational data vol. 2"
  │           （締切: 2026年7月30日）に間に合う
  │     完全OA、迅速な査読、IF 3.4
  │
  └── 第2選択: Statistics in Medicine
        理由: シミュレーション単独で最も受理されやすい
        方法論開発の標準的な投稿先

Phase 2（実データ検証を追加した場合）
  ├── American Journal of Epidemiology
  └── International Journal of Epidemiology
        理由: IFが高く影響力大、ただし実データが必要

Phase 3（理論的基盤を強化した場合）
  └── Biometrics
        理由: コヒーレンス度指標の理論的性質を証明できれば
```

### 論文分割の可能性

本研究の内容は、以下のように複数の論文に分割して投稿することも可能：

| 論文 | 焦点 | 推奨投稿先 |
|------|------|-----------|
| 論文A（方法論） | 決定力ベース層別化のシミュレーション評価 | Statistics in Medicine or BMC Med Res Methodol |
| 論文B（指標開発） | コヒーレンス度指標の提案と検証 | Epidemiology（短報） |
| 論文C（応用） | 実データへの適用と実用的ガイドライン | AJE or IJE |

## 総合的な推奨

**現段階での最善の選択は BMC Medical Research Methodology の特集号 "Causal inference and observational data vol. 2"（締切: 2026年7月30日）** である。理由：

1. テーマが本研究と直接合致
2. 特集号は通常号より受理率が高い傾向
3. 完全OAで可視性が高い
4. IF 3.4は方法論誌として十分
5. 締切まで約4ヶ月あり、論文執筆に十分な時間がある
6. シミュレーション単独の論文が受理可能

ただし、**長期的にはPhase 2（実データ検証の追加）を行い、AJEまたはIJEへの投稿を目指すことで、研究のインパクトを最大化できる**。
