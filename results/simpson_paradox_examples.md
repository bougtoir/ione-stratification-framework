# 実証セクションに使用可能な既報シンプソンのパラドックス事例

## 論文構成の想定

```
論文全体
├── 論理セクション（Theory）：コヒーレント集団の定義、コヒーレンス度指標の理論的導出
└── 実証セクション（Empirical）：既知のシンプソンのパラドックス事例に本手法を適用
    → 提案手法がパラドックスの原因となる隠れた群構造を検出できることを実データで示す
```

---

## 推奨事例

### ★第1推奨：腎結石治療データ（Charig et al. 1986, BMJ）

| 項目 | 内容 |
|------|------|
| 出典 | Charig CR, Webb DR, Payne SR, Wickham JE. BMJ 1986; 292: 879-882 |
| DOI | 10.1136/bmj.292.6524.879 |
| N | 700名（治療A: 350名、治療B: 350名） |
| 変数 | 治療法（A=開腹手術 / B=経皮的腎結石摘出術）、結石サイズ（大/小）、成功/失敗 |
| パラドックス | 全体: B(83%) > A(78%)。小結石: A(93%) > B(87%)。大結石: A(73%) > B(69%) |
| 隠れた交絡因子 | 結石サイズ（重症例に開腹手術Aが多く選択された） |
| データ入手性 | **公開済み**。論文Table + [OpenDataBay CSV](https://www.opendatabay.com/data/healthcare/d08d5089-9fe2-4dd2-9eb6-598940602608) |

**本研究への適用方法：**
- 「治療法」を曝露(exposure)、「成功/失敗」をアウトカム(Y)とする
- 治療選択に関連する一般変数（患者の臨床指標等）からの層別化で、結石サイズという「隠れた重大変数」を検出できるかを検証
- **制約**: 変数が少なく（治療・結石サイズ・成功の3変数）、一般変数X群がないため、**概念実証（illustrative example）としてのみ使用可能**。本手法の完全な検証には不向き
- **活用法**: パラドックスの発生メカニズムをコヒーレンス度指標C1で可視化する。全体のC1値 vs 結石サイズで分割後のC1値を比較し、「インコヒーレントな集団を検出できる」ことを示す

---

### ★第2推奨：UC Berkeley大学院入学データ（Bickel et al. 1975, Science）

| 項目 | 内容 |
|------|------|
| 出典 | Bickel PJ, Hammel EA, O'Connell JW. Science 1975; 187: 398-404 |
| DOI | 10.1126/science.187.4175.398 |
| N | 12,763名（男性8,442名、女性4,321名）、6学部 |
| 変数 | 性別、学部（A-F）、合否 |
| パラドックス | 全体: 男性44% > 女性35%。学部別: 多くの学部で女性の合格率が高い |
| 隠れた交絡因子 | 学部（女性は競争率の高い学部に多く志願した） |
| データ入手性 | **Rの組み込みデータセット** `UCBAdmissions` + [CSV](https://waf.cs.illinois.edu/discovery/berkeley.csv) |

**本研究への適用方法：**
- 「性別」を曝露、「合否」をアウトカムとする
- 学部ごとの応募者特性（暗黙の一般変数）から「学部」という隠れた群構造を検出
- **利点**: 最も有名な事例であり、読者の認知度が高い。6学部というクラスタ構造が明確
- **制約**: 腎結石同様、一般変数Xが少ない。ただし12,763名と十分なサンプルサイズ
- **活用法**: 全体集団のコヒーレンス度C1が低い（インコヒーレント）ことを示し、学部別に分割するとC1が改善することを実証。提案するコヒーレンス度指標の「サブ解析推奨」機能のデモンストレーション

---

### ★★第3推奨（最も推奨）：COVID-19致死率データ（von Kügelgen et al. 2021, IEEE TAI）

| 項目 | 内容 |
|------|------|
| 出典 | von Kügelgen J, Gresele L, Schölkopf B. IEEE Trans Artif Intell 2021; 2(1): 18-27 |
| DOI | 10.1109/TAI.2021.3073088 |
| arXiv | 2005.07180 |
| N | >750,000症例（多国間・時系列） |
| 変数 | 国、年齢層（10歳刻み）、致死率（CFR）、時期 |
| パラドックス | 全年齢層でイタリア < 中国だが、全体ではイタリア > 中国 |
| 隠れた交絡因子 | 年齢分布の違い（イタリアは高齢者の症例比率が高い） |
| データ入手性 | **著者がGitHubで公開**（age-stratified CFR dataset） |

**本研究への適用方法：**
- 「国」を曝露、「致死率」をアウトカム、「年齢層」を隠れた重大変数とする
- **最大の利点**: 変数が豊富で、本手法が想定する「連続的な一般変数から隠れた群構造を検出する」シナリオに最も近い
- 年齢を「隠れた変数」として扱い、各国内の年齢分布の違いから生じるインコヒーレンスをC1指標で検出
- 時系列データがあるため、イタリアの医療崩壊前後でコヒーレンス度がどう変化するかも分析可能
- **制約**: 集計データであり個票データではない。ただし概念実証としては十分

### 第4候補：英国女性の喫煙と死亡率（Appleton, French & Vanderpump 1996）

| 項目 | 内容 |
|------|------|
| 出典 | Appleton DR, French JM, Vanderpump MPJ. Am Statistician 1996; 50(4): 340-341 |
| N | 1,314名（20年追跡） |
| 変数 | 喫煙状況、年齢層、死亡/生存 |
| パラドックス | 全体: 喫煙者の死亡率(24%) < 非喫煙者(31%)。年齢層別: 全層で喫煙者の死亡率が高い |
| 隠れた交絡因子 | 年齢（喫煙者群の方が若かった） |
| データ入手性 | 論文内のTable（集計レベル） |

**本研究への適用方法：**
- 「喫煙」を曝露、「死亡」をアウトカムとする
- 年齢が隠れた群構造として「喫煙者は若い→死亡率が低い」という見かけの関連を生むことを、C1指標で検出
- **利点**: 直感に反する結果（「喫煙者の方が長生き」）が非常にインパクトがある
- **制約**: 個票データの公開状況が不明。集計データのみの可能性

### 案1：複数事例の階層的適用（推奨）

```
実証セクション
├── 5.1 概念実証（Illustrative examples）
│   ├── 腎結石データ：最小限の変数でC1指標の基本的挙動を示す
│   │   → 全体C1（インコヒーレント）vs 結石サイズ別C1（コヒーレント）
│   └── Berkeley入学データ：6クラスタ構造をC1が検出できることを示す
│
└── 5.2 実質的適用（Substantive application）
    └── COVID-19 CFRデータ：年齢層という連続的変数からの
        隠れた群構造検出を本手法で実施
        → 提案手法がパラドックスを解消する方向に層別化できたかを評価
```

### 案2：単一事例の深掘り

COVID-19 CFRデータのみを使用し、以下を詳細に分析：
1. 全体集団でのC1評価 → インコヒーレントと判定
2. 提案手法（残差ベース層別化）による自動層別化
3. 層別化後のC1改善度と、真の年齢層構造との一致度（ARI/NMI）
4. パラドックスの解消度の定量的評価

## 実用上の注意

1. **個票データ vs 集計データ**：腎結石・Berkeleyは集計データが主であり、提案手法（PCA、残差ベース等）の直接適用には個票データが必要。COVID-19は年齢層別の集計だが、各国の公開データから個票レベルの再構成が可能
2. **倫理的配慮**：既に公開されたデータの二次利用であり、倫理審査は通常不要。ただし投稿先のポリシーを確認すべき
3. **権利関係**：Berkeley data (R built-in)、COVID-19 data (CC BY 4.0)、腎結石 (BMJ Open Access) — いずれも学術利用に問題なし
4. **本手法の設計との整合性**：本手法は「一般変数X（10程度）からの層別化」を想定しているため、変数の少ない腎結石・Berkeleyは完全な検証には不向き。**より多変量のデータセットを別途確保するか、COVID-19データの充実版を使うことを推奨**
