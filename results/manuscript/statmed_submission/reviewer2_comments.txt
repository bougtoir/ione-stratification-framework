Peer Review Comments - Second Round
Manuscript: IONE: Incoherence-Oriented Neutralisation and Extraction for Detecting Hidden Population Structure in Observational Studies - a Monte Carlo Simulation Study
Summary
The authors have made substantial revisions and have addressed several prior concerns, including narrowing the conceptual scope, adding a treatment variable to the simulation data-generating mechanism, including active comparators, reporting Monte Carlo standard errors, and reframing the empirical section as semi-synthetic illustration rather than validation. The revised manuscript is clearer and more appropriately cautious than the previous version.
However, several issues remain unresolved in the manuscript itself. The most important are internal inconsistencies in the bias-reduction metric, the definition of the ground-truth subgroup structure and oracle performance, the practical computability of W, and the circularity risk in outcome-informed residual stratification. These issues are central to interpretation of the simulation results and should be addressed before acceptance.
Major Comments
Correct the bias-reduction definition and all reported values. The Methods define bias reduction as 1 - |bias_stratified| / |bias_crude|, which is a relative reduction. Table 8, however, appears to report the absolute difference |bias_crude| - |bias_stratified|. For example, for Method 1B, bias_crude = 0.087 and bias_stratified = 0.013; the relative reduction would be approximately 85%, whereas the table reports 0.074 and the Abstract describes a 7.4% reduction. Please choose either an absolute bias reduction or a relative percentage reduction, revise the formula and table headings accordingly, and update the Abstract, Results, and Discussion so that the units and interpretation are consistent.
Clarify the ground-truth subgroup definition and the oracle ARI results. The Methods state that the true subgroup structure was defined by applying k-means to the standardized Z-space with K clusters. If that is the ground truth, then an oracle method that applies k-means to Z would be expected to have ARI near 1, not 0.353 in Table 4 or 0.429 in Table 9. If the true partition is instead based on another rule, such as discrete critical-variable categories or latent CATE classes, it should be defined explicitly. The current inconsistency makes it difficult to interpret the small ARI values for IONE methods and the comparison with the oracle baselines.
Reframe W unless a feasible real-data estimator is evaluated. W is defined using the true CATE, which is available in the simulation but not in real observational studies. The manuscript states that W could use an estimated CATE in practice, but it does not evaluate an estimated-W procedure, its uncertainty, or sensitivity to CATE model misspecification. Because the Abstract and Conclusions present C1 and W as a two-tier diagnostic for applied studies, the authors should either provide a practical estimation workflow and evaluate it, or clearly label W as a simulation performance metric rather than a directly usable diagnostic.
Address the remaining circularity in outcome-informed residual stratification. Sample splitting separates model fitting from stratum assignment, but Method 1B still assigns strata using the observed outcome Y through |Y - p_hat|. For a binary outcome, the manuscript correctly notes that this is a label-dependent transformation of predicted probability. If treatment effects are then estimated within strata defined partly by the outcome, the approach may induce selection or collider bias. The revision acknowledges this concern, but it does not fully resolve it. The authors should restrict residual-based stratification to exploratory diagnostics, use a discovery/evaluation split for downstream treatment-effect estimation, add a sensitivity analysis quantifying the induced bias, or otherwise justify why outcome-conditioned strata can support the intended inferential claims.
Temper the claim that C1 detects population incoherence. The definition of C1 is now internally more consistent, but its empirical behavior remains weak in the main simulation. In Table 4, C1 is very similar for random stratification (0.863), Method 1B (0.859), and the oracle k-means baseline (0.825). Table 7 similarly shows substantial overlap. The Abstract and Conclusions still say that C1 detects between-stratum heterogeneity, but the main simulation indicates limited discrimination. Please reframe C1 as an exploratory, inconsistently discriminating metric that requires calibration, rather than as a diagnostic whose detection performance has been established.
Align the semi-synthetic claims with the reported results. The Abstract states that all methods achieved ARI > 0.7 in the semi-synthetic illustrations when pseudo-general variables carried strong traces of the known confounder. Table 11 does not support this as written: the best ARI values are 0.851 for kidney stone, 0.746 for the Israeli vaccine example, 0.498 for smoking mortality, 0.082 for UC Berkeley, and 0.064 for COVID-19 CFR. If the Abstract refers to a subset of examples or methods, please specify that precisely; otherwise, revise the claim so it reflects the full set of semi-synthetic results.
Resolve the method-count and comparator taxonomy inconsistencies. The response letter says that four active comparators were added, including k-means. The manuscript Abstract lists three active comparators, the Methods text refers to eighteen methods as six proposed plus four comparators plus six PCA variants plus two baselines, and the method list elsewhere refers to three active comparators. Please provide one exact method inventory and keep the classification consistent across the Abstract, Methods, tables, and response letter. In particular, clarify whether k-means on covariates is an IONE method, an active comparator, or both.
Minor Comments
Continue removing language that implies subgroup recovery. The manuscript is more cautious than before, but phrases such as extracting coherent subpopulations and recovering hidden structure should be used sparingly given ARI values near zero in the primary simulation.
Replace or define the term coherence degree. The Background still refers to a quantitative indicator of population coherence or coherence degree. If the intended indicators are C1 and W, use those terms consistently; otherwise define coherence degree formally.
Explain why Method 1B should reveal hidden structure beyond outcome labeling. Because residual stratification for binary outcomes depends directly on Y, readers need a clearer rationale for why it captures hidden population structure rather than grouping subjects by observed outcome and predicted risk.
Give enough implementation detail outside the code repository. The manuscript or supplement should report key modeling choices such as logistic-regression regularization, standardization, random-forest settings, k-means initialization and number of starts, GMM covariance structure, convergence handling, and random seeds. A code repository is useful, but the paper should remain interpretable on its own.
Explain why oracle baselines are not upper bounds for every metric. Method 1B appears to outperform oracle baselines for bias reduction in Table 8, and oracle quantile on Z has higher W than oracle k-means on Z. These patterns may be valid, but they need a short explanation because readers will naturally expect oracle methods to provide an upper-bound reference.
Handle the C1 threshold cautiously. The Discussion mentions a provisional C1 < 0.05 threshold, but the main simulation produces C1 values around 0.8 for most methods, including random stratification. Either remove the threshold or explain exactly where it applies and why it should not be inferred from the primary simulation.
Check table numbering and supplemental labeling. The manuscript includes main tables followed by additional-file tables in the extracted text. Please ensure that main-text and supplementary tables are numbered distinctly and cited unambiguously.
Use comparator names consistently. For example, use either propensity score quintiles or PS quintiles consistently, and distinguish prognostic score from disease risk score if both are discussed in the Background.
Qualify the Morris 2021 source in the main text as well as the reference list. The reference note says this is a blog post rather than a peer-reviewed publication. The Results text should avoid calling all five examples published instances unless the non-peer-reviewed source is clearly described as a publicly available data-analysis example.
Consider adding a permanent code archive or commit hash. The GitHub URL improves reproducibility, but a tagged release, commit hash, or archived DOI would make the analyses more durable for peer review and publication.
