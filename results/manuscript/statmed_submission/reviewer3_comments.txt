The manuscript has incorporated several comments from the previous reviewers. However, I 
still find that there are many aspects that remain confusing for readers and require substantial 
revision. More fundamentally, it is difficult to assess the validity of the proposed 
methodology, and I believe that the overall direction of the study may need to be 
reconsidered. 

1.  Population incoherence and latent class models 

The Introduction states: 

"However, none of these approaches explicitly address the problem of population 
incoherence—the condition in which an apparently homogeneous study population actually 
comprises multiple coherent subpopulations with heterogeneous treatment effects." 

The authors use latent class models as an example of approaches that do not address the 
population incoherence problem. However, latent class models are one of the standard 
approaches for identifying hidden subgroups with heterogeneous treatment effects from 
observed data. In essence, latent class membership is modeled as a latent random variable, 
and the resulting latent classes can naturally be interpreted as coherent subpopulations with 
different treatment effects. 

Therefore, I find this discussion potentially misleading. In what sense are the hidden 
subgroups identified by latent class models fundamentally different from the "hidden 
populations" described by the authors? If the distinction is that the proposed framework 
assumes a different latent structure (e.g., continuous latent variables or another latent 
representation), this difference should be explicitly clarified. Otherwise, readers familiar with 
latent class analysis may find the current discussion confusing. 

2.  Recovering stratification from unmeasured confounders 

The manuscript appears to suggest that stratification based on important measured variables 
can be recovered from unmeasured confounders. This claim seems overly strong. At best, one 
might expect only partial recovery of the underlying stratification. Moreover, the numerical 
settings considered in the simulation studies appear to be particularly favorable to the 
proposed method, making it difficult to judge how well the method would perform under 
more realistic scenarios. 

3.  Assumption regarding unmeasured effect modifiers 

The authors assume that "unmeasured effect modifiers influence both measured covariates 
and the treatment effect." This is a rather restrictive assumption. It essentially assumes that 
the unmeasured confounders act as common causes of both the measured covariates and the 
treatment effect. While such a setting may be plausible in certain applications, it is unlikely to 
hold in many practical situations. The implications and limitations of this assumption should 
therefore be discussed more carefully. 

4.  Specification of the outcome model 

In the outcome model, the treatment variable (A) only interacts with Z. Is there a specific 
reason why interactions between X and Z, or between X and A, were not considered? 

In addition, because treatment interactions are included in the model, the parameter (\tau) can 
no longer be interpreted as the main treatment effect. When the treatment effect varies 
according to A, what exactly does the "main treatment effect" represent in this model? This 
point should be clarified. 

5.  Definition of the true subgroup structure 

The true subgroup structure is defined using K-means clustering, which is a relatively crude 
clustering algorithm. If Z is assumed to be available, I find it difficult to justify defining the 
true subgroup structure using K-means clustering. More fundamentally, what is the precise 
definition of the "hidden subgroup" in this study?   

6.  Definition of the oracle method 

The oracle method is not appropriately defined, making it difficult to interpret situations in 
which another method outperforms the oracle. Since the oracle represents the analysis under 
the assumption that Z is observed, it is difficult to understand how a method that does not 
observe Z can achieve better performance (for large sample sizes). If this occurs, it may 
indicate a fundamental problem in the analysis pipeline used to define the oracle itself, rather 
than superior performance of the proposed method.
