## 1. 背景と問題意識

### 1.1 過去起点コホート研究における根本的課題

過去起点（後ろ向き）コホート研究では、曝露割り付けが研究者の制御下にないため、以下のバイアスが不可避的に発生する：

- **交絡バイアス（Confounding Bias）**：曝露と結果の両方に影響する第三の変数が、見かけ上の因果関係を生み出す
- **シンプソンのパラドックス**：集団全体で観察される関連の方向が、サブグループに分割すると逆転する現象。交絡の一特殊形態として理解できるが、必ずしも交絡のみに起因するわけではない
- **偶然変動（Random Fluctuation）**：有限サンプルに起因するランダムな誤差が、特にサブグループ解析において効果推定値を不安定にする

さらに、以下のバイアス・問題も過去起点コホート研究では不可避であり、本研究のアプローチによって改善しうる：

- **効果修飾の見落とし（Undetected Effect Modification）**：曝露の効果が部分集団ごとに真に異なるにもかかわらず、全体として単一の「平均的」効果を報告してしまう問題。交絡とは本質的に異なり、「効果そのものが部分集団間で異質である」状態を指す。例：薬剤Aが若年群では有効（OR=0.5）、高齢群では無効（OR=1.2）であるのに、全体で「やや有効（OR=0.8）」と報告される場合、いずれの部分集団にも該当しない知見が導かれる。コヒーレンス度指標はまさにこの隠れた効果修飾を検出するために設計される
- **生態学的誤謬（Ecological Fallacy）**：集団レベルで観察された関連を、そのまま個人レベルの関連として解釈する誤り。シンプソンのパラドックスと密接に関連するが、推論の方向性が異なる（集団→個人への不適切な一般化）。インコヒーレントな集団全体から得られた知見を個人に適用することは、まさに生態学的誤謬のリスクを孕む。コヒーレントな部分集団内であれば、集団レベルの知見と個人レベルの真の効果が一致しやすくなり、この誤謬が緩和される
- **非崩壊性（Non-collapsibility）**：オッズ比などの効果指標は、交絡が存在しなくても、周辺効果（集団全体の効果）と条件付き効果（部分集団内の効果）が一致しないという数学的性質を持つ。これは指標自体の構造的問題であり、バイアスとは区別されるが、実務上は「集団全体のORと各層のORが異なる」という混乱を招く。均質な層内で条件付き効果を推定すれば、非崩壊性による乖離が最小化される

### 1.2 シンプソンのパラドックスの本質的意味

シンプソンのパラドックスは単なる統計的アーティファクトではなく、以下の本質的示唆を含む：

> **「複数の独立してコヒーレントな（内部的に均質な）集団を内包する、インコヒーレントな集団全体から得られた知見を、個々のコヒーレント集団に適用する際は慎重であるべき」**

この問題は生態学的誤謬（Ecological Fallacy）と深く関連する：インコヒーレントな集団から得られた「全体の効果」を個人に適用することは、集団レベルの知見を個人レベルに不適切に一般化する誤りに他ならない。さらに、効果修飾が隠れている場合、全体の「平均的」効果はいずれの部分集団にも当てはまらない虚構の値となりうる。

すべての研究の対象集団はこのような**入れ子型の集団構造**を持つ可能性がある。このことは以下を意味する：

```
┌──────────────────────────────────────────────────────────────────┐
│  研究対象集団（インコヒーレント＝見かけ上ひとつの集団）            │
│                                                                    │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐        │
│   │ 集団A     │  │ 集団B     │  │ 集団C     │  │ 集団D     │        │
│   │ (コヒー   │  │ (コヒー   │  │ (コヒー   │  │ (コヒー   │        │
│   │  レント)  │  │  レント)  │  │  レント)  │  │  レント)  │        │
│   │           │  │           │  │           │  │           │        │
│   │ 効果: +   │  │ 効果: +   │  │ 効果: +   │  │ 効果: +   │        │
│   └──────────┘  └──────────┘  └──────────┘  └──────────┘        │
│                                                                    │
│   全体の見かけ上の効果: −  （シンプソンのパラドックス）             │
│                                                                    │
│   問題：集団A〜Dの存在を「知らない」場合、                         │
│         全体から得た「効果 −」をそのまま結論としてしまう             │
└──────────────────────────────────────────────────────────────────┘
```

### 1.3 既存の疑似ランダム化手法とその限界

| 手法 | 原理 | 主な限界 |
|------|------|----------|
| **傾向スコア（PS）** | 観察された共変量から治療割り付け確率を推定し、同スコアで層別化・マッチング | 未測定交絡の調整不可；治療割り付けモデルの正確性に依存 |
| **予後スコア（Prognostic Score）** | 共変量からアウトカムリスクを推定し層別化に使用（Hansen 2008; Aikens et al., 2020） | 未測定交絡の直接調整は不可；ただし感度分析のパワーが向上 |
| **疾患リスクスコア（DRS）** | 非曝露群のみでアウトカム予測モデルを構築 | PS同様、未測定交絡に脆弱 |
| **操作変数法（IV）** | 治療には影響するがアウトカムには直接影響しない変数を利用 | 適切なIVの入手が困難；弱い道具変数問題 |
| **高次元傾向スコア（hdPS）** | 大量の代理変数（診断コード・処方コード等）からPS推定（Schneeweiss et al., 2009） | 計算コスト大；代理変数の選択に恣意性；操作変数・衝突変数の混入リスク |

**既存手法の共通する限界**：いずれも「測定された変数による調整」が前提であり、**測定されていない変数によって形成される集団構造を検出・抽出する手法は確立されていない**。

### 1.4 本研究のストーリーライン：シミュレーション検証から実データ応用へ

本研究の最終目標は以下のパイプラインの確立である：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
最終目標：コヒーレント集団の抽出による正しい知見の獲得
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Step 1. 一般変数のみでデータを層別化する
        （測定変数の多変量パターンや予測力を利用）
                    ↓
  Step 2. 層＝コヒーレント集団の候補として扱う
        （各層内の均質性を評価）
                    ↓
  Step 3. 層内で分析を実施する
        （各コヒーレント集団内での正しい知見を得る）
                    ↓
  Step 4. コヒーレンス度指標を提示する
        （「これ以上分割する必要があるか」の判断基準）
                    ↓
  Step 5. 全体知見と部分知見の統合
        （シンプソンのパラドックスの回避・メタ分析的統合）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

この最終目標に向けて、本研究ではまず**シミュレーションによる原理的検証**を行う：

```
シミュレーション検証の論理：

  前提：重大変数Z（年齢・性別等）が既知のデータを生成する
        ↓
  操作：Zを「未測定」として扱い、一般変数Xのみで層別化する
        ↓
  問い：Xのみの層別化で、Zに基づく真の群構造を再現できるか？
        ↓
  もしYES → 「真に未測定の重大変数が存在する実データでも、
              一般変数だけで見えない群構造を検出・層別化できる」
              という手法の妥当性が支持される
        ↓
  実データ応用：Table 1 から均質性が明らかでない場合に
                サブ解析を推奨するための指標を提供する
```

### 1.5 本研究で検証する2つの仮説

- **仮説A（決定力残差仮説）**：一般変数からアウトカムへの予測力・予測残差のパターンが、未測定重大変数の影響を反映した構造を持ち、これによる層別化が真の群構造を再現する
- **仮説B（特徴量空間仮説）**：重大変数は一般変数の分布に系統的な影響を及ぼすため、一般変数の多変量パターンに「痕跡」が残り、アウトカム情報を使わずとも群構造を検出できる

## 2. データセット仕様

### 2.1 概要

シミュレーションにより、真の因果構造が既知のデータセットを生成する。重大変数Zは生成には使用するが、手法の入力からは意図的に除外する。

```
データセット構成:
├── 一般説明変数 X = {X1, X2, ..., X10}  （血液検査等を想定）
├── 重大説明変数 Z = {Z1, Z2, Z3}        （年齢・性別等を想定、「未測定」として扱う）
└── 被説明変数   Y                        （イベント発生 0/1）
```

### 2.2 変数の詳細定義

#### 2.2.1 重大変数 Z（意図的に「未測定」として扱う）

| 変数 | 想定 | 型 | 生成方法 |
|------|------|-----|----------|
| Z1 | 年齢 | 連続量 | N(60, 12²)、範囲 [20, 95] |
| Z2 | 性別 | 二値 | Bernoulli(0.5) |
| Z3 | BMI区分 | 順序(3水準) | Multinomial(0.3, 0.4, 0.3) |

#### 2.2.2 一般変数 X（「測定済み」として使用）

血液検査値を模擬。重大変数Zからの影響を受けるように生成する。

| 変数 | 想定 | Zからの影響度 |
|------|------|---------------|
| X1 | 血糖値(HbA1c) | Z1: 強, Z3: 強 |
| X2 | 総コレステロール | Z1: 中, Z2: 弱 |
| X3 | 収縮期血圧 | Z1: 強 |
| X4 | ALT | Z3: 中 |
| X5 | クレアチニン | Z1: 中, Z2: 弱 |
| X6 | ヘモグロビン | Z2: 強 |
| X7 | 白血球数 | Z1: 弱 |
| X8 | アルブミン | Z1: 中 |
| X9 | CRP | Z1: 弱, Z3: 弱 |
| X10 | 尿酸 | Z2: 中, Z3: 弱 |

#### 2.2.3 データ生成プロセス（因果DAG）

```
Z1(年齢) ──┬──→ X1, X2, X3, X5, X7, X8, X9  （一般変数への影響）
            ├──→ Y（アウトカムへの直接効果）
            └──→ X の一部を介した間接効果

Z2(性別) ──┬──→ X2, X5, X6, X10
            └──→ Y

Z3(BMI)  ──┬──→ X1, X4, X9, X10
            └──→ Y

X1..X10  ──────→ Y （一般変数の直接効果、ただしZより弱い）

ε (ノイズ) ────→ Y
```

#### 2.2.4 アウトカム生成モデル

```
logit(P(Y=1)) = β₀ 
               + β_Z1·Z1 + β_Z2·Z2 + β_Z3·Z3      # 重大変数の効果（大）
               + Σ β_Xi·Xi                            # 一般変数の効果（小〜中）
               + γ·(Z1×Z2)                            # 交互作用項（オプション）
               + ε
```

パラメータ設定の指針：
- 重大変数の効果サイズ：OR = 1.5〜3.0（臨床的に意味ある大きさ）
- 一般変数の効果サイズ：OR = 1.0〜1.3（弱〜中程度）
- イベント発生率：全体で10〜20%程度（典型的なコホート研究を想定）

### 2.3 サンプルサイズ

| シナリオ | N | 目的 |
|----------|---|------|
| 小規模 | 500 | 偶然変動の影響評価 |
| 中規模 | 2,000 | 主要検証 |
| 大規模 | 10,000 | 理論的限界の評価 |

### 2.4 シミュレーション反復

各シナリオについて 500〜1,000 回のモンテカルロシミュレーションを実施し、手法の安定性を評価する。

## 3. 手法1：一般変数から被説明変数への決定力による層別化（主手法）

### 3.1 概念と有望性

一般変数 X のみからアウトカム Y を予測するモデルを構築し、その「予測の確信度・予測残差の大きさ」によってデータを層別化する。

**キーアイデア**：X だけでは Y を十分に説明できない場合、予測残差が大きいサンプルは「X以外の未測定要因（= Z）の影響が大きいサンプル」である可能性が高い。この残差のパターンが系統的であれば、それは未測定の群構造を反映している。

**なぜ手法1（主手法）とするか**：
- **Y の情報を活用する分、ターゲットが明確**：「Xで説明できない部分 ≒ Zの痕跡」という論理が直接的
- **予後スコア（Hansen 2008）との理論的接続**が強く、先行研究に基づく正当化がしやすい
- **コヒーレンス度指標との親和性が高い**：予測残差の構造化度合い → コヒーレンス度の自然な定義に繋がる

### 3.2 予測モデルと決定力指標の候補

#### 方法1A：予測確率（Predicted Probability）ベース
```
手順:
1. X1〜X10 を説明変数、Y を被説明変数としたロジスティック回帰モデルを構築
2. 各サンプルの予測確率 p_hat を算出
3. p_hat の分位点でデータを層別化
   → 「一般変数で予測しやすいグループ」と「予測しにくいグループ」を分離
```

- **解釈**：予後スコア（Prognostic Score）と本質的に同じ概念。ただし「重大変数を意図的に除外」した状態で推定する点が独自
- **利点**：解釈性が高い、先行研究との接続が明確
- **懸念**：線形性の仮定；過学習の管理が必要

#### 方法1B：予測残差の絶対値ベース
```
手順:
1. 同上のモデルから予測確率 p_hat を得る
2. 残差 r = Y - p_hat を算出
3. |r| の大きさで層別化
   → 残差大群 = X では説明できない要因の影響が強い群
```

- **利点**：直観的にわかりやすい；「未説明部分」を直接的に切り出す
- **懸念**：二値アウトカムの残差分布が歪む；Y=1かつp_hat≈0のサンプルと、Y=0かつp_hat≈1のサンプルは質的に異なる可能性

#### 方法1C：交差検証型決定力スコア
```
手順:
1. データをK-fold に分割
2. 各foldについて、残りのfoldでモデルを学習し、holdout foldの予測確率を得る
3. 交差検証予測確率を「決定力スコア」として使用
4. 層別化に用いる
```

- **利点**：過学習の回避（パイロットデザイン（Aikens et al., 2020）の思想と共通）
- **懸念**：計算コスト増

#### 方法1D：機械学習モデルの不確実性ベース
```
手順:
1. X1〜X10 を入力としたRF / GBM / ニューラルネットでYを予測
2. モデル不確実性（RF: tree間の分散、NN: MCドロップアウトの分散）を算出
3. 不確実性の大きさで層別化
```

- **利点**：非線形な予測力の「行き詰まり」を捕捉
- **懸念**：モデルの不確実性 ≠ 入力変数の情報不足（アレアトリック vs エピステミック不確実性）の区別が必要

```
│                                                              │
```

## 4. 手法2：一般変数由来の特徴量得点による層別化（補完的手法）

### 4.1 概念

一般変数 X1〜X10 から多変量的な「特徴量得点」を算出し、この得点によってデータを層（stratum）に分割する。**Yの情報を一切使わない**ことが手法1との根本的な違い。

**補完的手法とする理由**：
- Yの情報を使わないため、ターゲットが間接的（Zの痕跡がXの共分散構造に残っていることを前提とする）
- ただし「Yに依存しない群構造の発見」として独自の価値がある：Yの定義が変わっても同じ層別化を使い回せる

### 4.2 特徴量得点の算出方法（候補）

#### 方法2A：主成分分析（PCA）ベース
```
手順:
1. X1〜X10 を標準化
2. PCA を実施し、第1〜第k主成分を抽出
3. 第1主成分得点（PC1）または複数主成分の重み付き合成得点を「特徴量得点」とする
4. 得点の分位点（四分位・五分位等）でデータを層別化
```

- **利点**：解釈が明快、計算が軽い
- **懸念**：PCAは分散最大方向を捉えるが、それが必ずしもZの影響方向と一致するとは限らない

**累積寄与率シナリオ**：臨床データでは変数間の相関が弱いことが多く、累積寄与率が高くならないケースが一般的。以下の複数シナリオを想定：

| シナリオ | 累積寄与率の閾値 | 想定される状況 | 備考 |
|----------|-----------------|---------------|------|
| **低寄与率** | 40% | 変数間の相関が弱い臨床データ。PC1〜2で40%程度しか説明できない | 多くの臨床研究で典型的 |
| **中寄与率** | 60% | 中程度の相関構造。PC1〜4程度で60%到達 | 比較的均質なデータ |
| **高寄与率** | 80% | 強い相関構造。PC1〜5程度で80%到達 | 理想的だが臨床では稀 |
| **固定次元** | k=1, 2, 3（次元数固定） | 寄与率閾値ではなく次元数で制御 | 寄与率に依らない比較用 |

さらに、寄与率の低さ自体が「Zの痕跡がXに残りにくい」ことを示唆する可能性がある。**累積寄与率と手法の有効性の関係**を検証項目に含める。

#### 方法2B：クラスタリングベース（k-means / 階層的クラスタリング）
```
手順:
1. X1〜X10 を標準化
2. k-means（k=3〜6）または階層的クラスタリングを実施
3. クラスタ帰属をそのまま「層」とする
```

- **利点**：非線形な構造も捉えうる
- **懸念**：クラスタ数kの選択に恣意性；高次元では距離ベースの手法が劣化する可能性

#### 方法2C：オートエンコーダ潜在表現ベース
```
手順:
1. X1〜X10 を入力とするオートエンコーダを訓練
2. ボトルネック層（2〜3次元）の潜在表現を得る
3. 潜在表現空間でクラスタリングまたは分位点分割
```

- **利点**：非線形な多様体構造を捉える能力が高い
- **懸念**：ブラックボックス性；ハイパーパラメータの影響大

#### 方法2D：ランダムフォレスト近接度（Proximity）ベース
```
手順:
1. X1〜X10 を特徴量として教師なしランダムフォレスト（合成データ法）を訓練
2. サンプル間の近接度行列を算出
3. 近接度行列に基づく多次元尺度法（MDS）またはクラスタリングで層別化
```

- **利点**：変数間の複雑な相互作用を暗黙的に捕捉
- **懸念**：計算コスト；結果の再現性

### 4.3 層別化の設定

| パラメータ | 候補値 | 備考 |
|------------|--------|------|
| 層数 | 3, 4, 5, 10 | 偶然変動とのトレードオフ |
| 分割基準 | 等人数分割 / 等間隔分割 | |
| PCA累積寄与率 | 40%, 60%, 80%, 固定次元(k=1,2,3) | 臨床実態を反映した複数シナリオ |
| 次元削減法 | PCA / AE / RF-Proximity | 各々の比較 |

## 5. 検証3：未測定重大変数による群構造の再現能力の評価

### 5.1 評価の枠組み

シミュレーションでは Z の真値が既知であるため、以下の問いを定量的に評価できる：

> **手法1・2で作成された「層（stratum）」は、Z によって定義される「真の群構造」とどの程度一致するか？**

ここでの一致は「代理指標としての検証」ではなく、**「未測定の重大変数が存在する状況で、一般変数のみから群構造を再現できるかの原理的証明」**である。

### 5.2 真の群構造の定義

重大変数 Z から真の群構造を以下のように定義する：

| 群構造の定義方法 | 詳細 |
|----------------|------|
| **離散化クラスタ** | Z1(年齢) を3区分 × Z2(性別) 2区分 × Z3(BMI) 3区分 = 最大18クラスタ |
| **Z空間クラスタリング** | Z1, Z2, Z3 の標準化空間で k-means（k を手法側の層数に合わせる） |
| **Z由来の予後リスク層** | Z のみからアウトカムを予測した予測確率の分位点による層 |

### 5.3 一致度の評価指標

#### (a) クラスタ一致度指標

| 指標 | 説明 | 適用場面 |
|------|------|----------|
| **Adjusted Rand Index (ARI)** | 偶然一致を補正したクラスタ一致度。[-1, 1]、1で完全一致 | クラスタ vs 層 |
| **Normalized Mutual Information (NMI)** | 情報理論ベースのクラスタ一致度。[0, 1] | クラスタ vs 層 |
| **V-measure** | 均質性(Homogeneity)と完全性(Completeness)の調和平均 | クラスタ vs 層 |

#### (b) 層内 Z 分布の均質性

| 指標 | 説明 |
|------|------|
| **層内 Z の分散比（ANOVA的）** | 層間分散 / 全分散。大きいほど層がZの情報を捕捉 |
| **層内 Z2(性別) のエントロピー** | 各層内の性別比が偏っているほどエントロピーが低い（= 層が性別を捕捉） |
| **η²（イータ二乗）** | 層を群変数、Zを従属変数としたときの効果量 |

#### (c) シンプソンのパラドックス解消度

| 指標 | 説明 |
|------|------|
| **方向一致率** | 全体効果とすべての層内効果の方向（正/負）が一致する割合 |
| **Cochran-Mantel-Haenszel検定** | 層別調整後の共通オッズ比と、未調整オッズ比の乖離 |

### 5.4 感度分析パラメータ

以下を変化させて手法の頑健性を評価：

| パラメータ | 変動範囲 | 目的 |
|------------|----------|------|
| Zの効果サイズ | OR 1.2〜5.0 | 重大変数の影響度に対する感度 |
| Z→X の影響経路の強さ | 相関 0.1〜0.7 | 間接的痕跡の濃さへの感度 |
| X→Y の直接効果の大きさ | OR 1.0〜2.0 | 一般変数自体の予測力への感度 |
| ノイズレベル | 低/中/高 | 偶然変動への頑健性 |
| Zの変数数 | 1, 2, 3 | 未測定変数の複雑さへの感度 |

### 5.5 コヒーレント集団抽出の評価

従来の「クラスタ一致度」に加え、本研究の最終目標に直結する評価軸を設ける：

#### (a) 層内コヒーレンスの評価

> **「抽出された各層は、内部的に均質な（コヒーレントな）集団として扱えるか？」**

この評価は、以下の3つの問題への対処を同時に検証する：
- **効果修飾の見落としの防止**：層間で効果が異なるなら、それは未検出の効果修飾が存在していたことを意味する
- **生態学的誤謬の緩和**：層内がコヒーレントであれば、集団レベルの知見≈個人レベルの知見となる
- **非崩壊性の影響最小化**：均質な層内での条件付き効果推定は、周辺効果との乖離を最小化する

| 指標 | 説明 | 意味 |
|------|------|------|
| **層内効果の同質性検定（Cochran's Q / I²）** | メタ分析の異質性指標を層間に適用。各層を「サブ研究」とみなす | I² が低い ≒ 層内がコヒーレント（効果修飾がない） |
| **層内 X→Y 関係の安定性** | 各層内で X→Y の回帰係数がどの程度一定か（係数の層間分散） | 低分散 ≒ 同質的なメカニズム（効果修飾なし） |
| **層内残差分布の形状** | 各層内の予測残差が正規分布に近いか（歪度・尖度・SW検定） | 正規に近い ≒ 系統的な未説明要因が少ない |
| **層間効果の方向・大きさの異質性** | 各層の効果推定値の方向（正/負）と大きさの分散 | 層間で効果の方向が反転 → 強い効果修飾の存在 |

#### (b) コヒーレンス度指標の定義（中核概念）

本研究のキーアウトプットの一つとして、**集団のコヒーレンス度を定量化する指標** C を提案する：

```
コヒーレンス度指標 C の候補定義：

  C₁（異質性ベース）:
     C₁ = 1 - I²(層間)
     I² は層間の効果推定値の異質性。C₁ ≈ 1 なら層間で効果が一致 → 全体がコヒーレント

  C₂（残差構造ベース）:
     C₂ = 1 - (層内残差の系統的成分 / 全残差分散)
     層内残差にパターンがなければ C₂ ≈ 1 → 層内がコヒーレント

  C₃（予測安定性ベース）:
     C₃ = 1 - CV(層別効果推定値のブートストラップ分散)
     層別化による効果推定値が安定しているほど C₃ が高い

  C₄（エントロピーベース）:
     C₄ = 1 - H(層内Z分布) / H_max
     層内のZ分布が偏っている（＝隠れた群変数を捕捉）ほど C₄ が高い
     （※シミュレーションでの検証用。実データではZが未知なので直接使えない）
```

**コヒーレンス度指標の活用イメージ**：

```
臨床研究者のワークフロー：

  1. Table 1 を作成する（従来の記述統計）
  2. 手法1 or 2 でデータを層別化する
  3. コヒーレンス度 C を算出する
  4. 判断：
     ┌─ C ≥ 閾値 → 全体を均質集団として分析してよい
     │             （これ以上サブグループを想定する必要なし）
     └─ C < 閾値 → ★サブ解析を推奨★
                    各層について個別に解析を実施し、
                    層間で結果が異なるかを確認すべき
```

**実データにおける適用条件**：C₁, C₂, C₃ はYとXのみから算出可能であり、Zの知識を必要としない。したがって実データに直接適用できる。C₄はシミュレーションでの手法検証用。

## 6. 検証4：疑似ランダム化の妥当性評価

### 6.1 「疑似ランダム化」の操作的定義

本研究における「疑似ランダム化が成立する」とは、以下を意味する：

> **手法1・2による層別化の後、各層内において Z の分布が（近似的に）均一化され、あたかもランダムに Z が割り当てられたかのような状態になること**

### 6.2 評価基準

#### (a) 共変量バランス指標（層内）

| 指標 | 説明 | 閾値の目安 |
|------|------|------------|
| **標準化平均差（SMD）** | 層内の Z の各水準間での共変量バランス | |SMD| < 0.1 で良好 |
| **分散比（Variance Ratio）** | 層内サブグループ間の分散の比 | 0.5〜2.0 の範囲で許容 |
| **KS統計量** | 連続変数の分布の全体的な類似度 | p > 0.05 |

#### (b) 因果効果推定の偏り

真の因果効果が既知（シミュレーション）であることを活かし：

| 指標 | 説明 |
|------|------|
| **バイアス** | E[θ_hat] - θ_true |
| **RMSE** | √(バイアス² + 分散) |
| **カバレッジ率** | 95%CIが真値を含む割合 |
| **シンプソンパラドックス発生率** | 層別後にパラドックスが解消される割合 |

#### (c) ベースライン手法との比較

本手法の妥当性を評価するために、以下のベースラインと比較する：

| 比較手法 | 説明 |
|----------|------|
| **無調整（Crude）** | 層別化なしの粗分析 |
| **真のZによる層別化（Oracle）** | Zを直接知っている場合の層別化（理論上の上限） |
| **傾向スコア層別化（PS）** | X を用いた傾向スコア（治療モデル型） |
| **完全な予後スコア層別化** | X + Z すべてを用いた予後スコア（実際は不可能だが上限として） |
| **ランダム層別化** | データをランダムに層に分割（下限ベースライン） |

#### (d) 偶然変動への対処の評価

| 評価項目 | 方法 |
|----------|------|
| **ブートストラップ安定性** | 1000回のブートストラップで層帰属の安定性を評価 |
| **層別化結果の再現性** | 異なるランダムシードで層割り当てがどの程度変動するか |
| **小サブグループの影響** | 層内サンプルサイズが小さい場合の推定量の分散増大を評価 |

### 6.3 疑似ランダム化とコヒーレント集団抽出の関係

疑似ランダム化とコヒーレント集団抽出は、同じ層別化操作の二つの側面である：

```
同じ層別化操作に対する二つの評価軸：

  層別化結果
    │
    ├── 疑似ランダム化の観点（検証4）
    │   「各層内でZがランダム化されているか？」
    │   → 層内でのZの均一性を評価
    │   → 均一 ≒ 各層が特定のZの組合せに対応するコヒーレント集団
    │
    ├── コヒーレント集団抽出の観点（検証3拡張）
    │   「各層は均質な部分集団として扱えるか？」
    │   → 層内での効果の同質性を評価
    │   → 同質 ≒ 層内でシンプソンのパラドックスが解消されている
    │
    └── バイアス緩和の観点（追加評価軸）
        「層別化により、効果修飾・生態学的誤謬・非崩壊性の問題が軽減されるか？」
        → 効果修飾：層間で効果が異なるなら、隠れた効果修飾が検出されたことを意味する
        → 生態学的誤謬：層内がコヒーレントなら、集団知見≈個人知見となり誤謬が緩和
        → 非崩壊性：均質層内の条件付きORは周辺効果との乖離が最小

  ★すべてが成立する場合：
    「未測定の重大変数によるコヒーレント集団を抽出でき、
     各集団内では偏りのない（疑似ランダム化された）分析が可能であり、
     効果修飾を検出し生態学的誤謬を回避した正しい知見を得られる」
    → 本研究の理想的な成功条件
```

| **ROC的曲線** | Z クラスタの検出力を「層数」をパラメータとして描画 |
| **シンプソンパラドックス解消図** | 全体効果 vs 層別効果の方向を視覚化 |
| **層内Zの分布図** | 各層におけるZ1(年齢)・Z2(性別)の分布をバイオリンプロットで表示 |
| **コヒーレンス度マップ** | コヒーレンス度 C を手法×層数×パラメータ設定で可視化し、閾値の最適化に活用 |

## 8. 理論的考察（ブレインストーミング段階のメモ）

### 8.1 この手法が機能する条件（予想）

1. **Z→X の影響が十分に強い場合**：Z の「痕跡」がXの多変量空間に残るため、層別化がZの群構造と一致しやすい
2. **X の次元がZの次元より十分に大きい場合**：10次元のXから2〜3次元のZを逆推定するのは、自由度の観点から原理的に可能
3. **Zの効果が線形的に X に反映される場合**：PCAベースの手法が特に有効と予想
4. **Z間に交互作用がある場合**：非線形手法（AE、RF）が線形手法を上回ると予想

### 8.2 この手法が失敗する条件（予想）

1. **Z→X の影響が弱い場合**：Xの空間にZの情報がほぼ残らない
2. **X→Y の直接効果が支配的な場合**：手法1（決定力ベース）の残差にZの情報が含まれなくなる
3. **複数のZが相互に相殺する影響を持つ場合**：PCA等の線形手法では分離できない
4. **サンプルサイズが小さい場合**：偶然変動が層別化の精度を圧倒する

### 8.3 傾向スコア法との理論的関係

- **傾向スコア法**は「治療の割り付け確率」でバランシングする ← **背景変数から治療方向** へ向かう矢印をモデル化
- **手法1（決定力ベース）**は「アウトカムへの予測力」で層別化する ← **背景変数からアウトカム方向** へ向かう矢印をモデル化
- **手法2（特徴量得点ベース）**は背景変数間の相互関係自体で層別化する ← **因果構造から独立** な、純粋にデータ駆動型のアプローチ

手法2は因果推論の枠組みでは「無情報な層別化」と見做される可能性があるが、Zの痕跡がXに残るなら有効。これは **「近接因果推論（Proximal Causal Inference）」** の概念に関連する可能性がある（Xがunmeasured Zのproxy）。

### 8.4 コヒーレンス度指標の理論的基盤

コヒーレンス度指標は、以下の既存概念と理論的に接続する：

| 既存概念 | 本研究との対応 |
|----------|---------------|
| **メタ分析のI²統計量** | 層を「サブ研究」とみなし、効果の異質性をI²で評価 → C₁の基盤 |
| **混合モデルのクラス数選択（BIC/AIC）** | コヒーレント集団の「最適数」の決定にBIC的情報量基準を応用 |
| **潜在クラス分析（LCA）** | 観測変数から潜在クラスを推定する既存手法。本研究は「臨床的に解釈可能な層別化」を志向する点が異なる |
| **処理効果の異質性（HTE: Heterogeneous Treatment Effects）** | 因果推論における効果修飾の検出。本研究はHTEの「原因」としての群構造に着目 |
| **生態学的誤謬（Ecological Fallacy）** | 集団→個人への不適切な一般化。本研究はコヒーレント集団を抽出することで、集団知見≈個人知見となる状態を実現 |
| **非崩壊性（Non-collapsibility）** | 周辺効果≠条件付き効果となる数学的性質。均質層内の条件付き効果推定で乖離を最小化 |

**重要な理論的問い**：コヒーレンス度の閾値は普遍的に設定できるか、それともデータ特性に依存するか？ → Phase 2〜3で検証

### 8.5 本研究が対処するバイアス群の統合的理解

本研究のアプローチ（コヒーレント集団の抽出）が対処するバイアス・問題群は、互いに関連しつつも異なる概念である。その関係性を整理する：

```
本研究が対処するバイアス・問題の構造：

  根本原因：「研究対象集団が複数のコヒーレント集団を内包する」
    │
    ├─→ 交絡バイアス：隠れた群構造が曝露とアウトカムの両方に関連
    ├─→ シンプソンのパラドックス：集団全体の効果が部分集団で逆転
    ├─→ 効果修飾の見落とし：効果が真に異なるのに「平均」を報告
    ├─→ 生態学的誤謬：集団知見を個人に不適切に適用
    └─→ 非崩壊性の影響：周辺効果≠条件付き効果となる乖離
            │
            ↓
  対処：「コヒーレント集団を抽出し、各集団内で分析する」
    │
    ├─→ 交絡：層内でZが均一化 → 交絡バイアスが軽減
    ├─→ シンプソン：層内で効果の方向が一貫 → パラドックスが解消
    ├─→ 効果修飾：層間の効果差が明示的に検出可能
    ├─→ 生態学的誤謬：コヒーレント層内なら集団知見≈個人知見
    └─→ 非崩壊性：均質層内の条件付き効果で乖離最小化
```

このように、本研究のアプローチは「隠れた群構造が存在する」という単一の根本原因に対処することで、複数のバイアス・問題を同時に緩和する可能性を持つ。

### 8.6 偶然変動への対処の方針

|------|------|

## 1. 背景と問題意識

### 1.1 過去起点コホート研究における根本的課題

過去起点（後ろ向き）コホート研究では、曝露割り付けが研究者の制御下にないため、以下のバイアスが不可避的に発生する：

- **交絡バイアス（Confounding Bias）**：曝露と結果の両方に影響する第三の変数が、見かけ上の因果関係を生み出す
- **シンプソンのパラドックス**：集団全体で観察される関連の方向が、サブグループに分割すると逆転する現象。交絡の一特殊形態として理解できるが、必ずしも交絡のみに起因するわけではない
- **偶然変動（Random Fluctuation）**：有限サンプルに起因するランダムな誤差が、特にサブグループ解析において効果推定値を不安定にする

さらに、以下のバイアス・問題も過去起点コホート研究では不可避であり、本研究のアプローチによって改善しうる：

- **効果修飾の見落とし（Undetected Effect Modification）**：曝露の効果が部分集団ごとに真に異なるにもかかわらず、全体として単一の「平均的」効果を報告してしまう問題。交絡とは本質的に異なり、「効果そのものが部分集団間で異質である」状態を指す。例：薬剤Aが若年群では有効（OR=0.5）、高齢群では無効（OR=1.2）であるのに、全体で「やや有効（OR=0.8）」と報告される場合、いずれの部分集団にも該当しない知見が導かれる。コヒーレンス度指標はまさにこの隠れた効果修飾を検出するために設計される
- **生態学的誤謬（Ecological Fallacy）**：集団レベルで観察された関連を、そのまま個人レベルの関連として解釈する誤り。シンプソンのパラドックスと密接に関連するが、推論の方向性が異なる（集団→個人への不適切な一般化）。インコヒーレントな集団全体から得られた知見を個人に適用することは、まさに生態学的誤謬のリスクを孕む。コヒーレントな部分集団内であれば、集団レベルの知見と個人レベルの真の効果が一致しやすくなり、この誤謬が緩和される
- **非崩壊性（Non-collapsibility）**：オッズ比などの効果指標は、交絡が存在しなくても、周辺効果（集団全体の効果）と条件付き効果（部分集団内の効果）が一致しないという数学的性質を持つ。これは指標自体の構造的問題であり、バイアスとは区別されるが、実務上は「集団全体のORと各層のORが異なる」という混乱を招く。均質な層内で条件付き効果を推定すれば、非崩壊性による乖離が最小化される

### 1.2 シンプソンのパラドックスの本質的意味

シンプソンのパラドックスは単なる統計的アーティファクトではなく、以下の本質的示唆を含む：

> **「複数の独立してコヒーレントな（内部的に均質な）集団を内包する、インコヒーレントな集団全体から得られた知見を、個々のコヒーレント集団に適用する際は慎重であるべき」**

この問題は生態学的誤謬（Ecological Fallacy）と深く関連する：インコヒーレントな集団から得られた「全体の効果」を個人に適用することは、集団レベルの知見を個人レベルに不適切に一般化する誤りに他ならない。さらに、効果修飾が隠れている場合、全体の「平均的」効果はいずれの部分集団にも当てはまらない虚構の値となりうる。

すべての研究の対象集団はこのような**入れ子型の集団構造**を持つ可能性がある。このことは以下を意味する：

```
┌──────────────────────────────────────────────────────────────────┐

│                                                                    │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐        │
│   │ 集団A     │  │ 集団B     │  │ 集団C     │  │ 集団D     │        │
│   │ (コヒー   │  │ (コヒー   │  │ (コヒー   │  │ (コヒー   │        │
│   │  レント)  │  │  レント)  │  │  レント)  │  │  レント)  │        │
│   │           │  │           │  │           │  │           │        │
│   │ 効果: +   │  │ 効果: +   │  │ 効果: +   │  │ 効果: +   │        │
│   └──────────┘  └──────────┘  └──────────┘  └──────────┘        │
│                                                                    │
│   全体の見かけ上の効果: −  （シンプソンのパラドックス）             │
│                                                                    │
```

### 1.3 既存の疑似ランダム化手法とその限界

| 手法 | 原理 | 主な限界 |
|------|------|----------|
| **傾向スコア（PS）** | 観察された共変量から治療割り付け確率を推定し、同スコアで層別化・マッチング | 未測定交絡の調整不可；治療割り付けモデルの正確性に依存 |
| **予後スコア（Prognostic Score）** | 共変量からアウトカムリスクを推定し層別化に使用（Hansen 2008; Aikens et al., 2020） | 未測定交絡の直接調整は不可；ただし感度分析のパワーが向上 |
| **疾患リスクスコア（DRS）** | 非曝露群のみでアウトカム予測モデルを構築 | PS同様、未測定交絡に脆弱 |
| **操作変数法（IV）** | 治療には影響するがアウトカムには直接影響しない変数を利用 | 適切なIVの入手が困難；弱い道具変数問題 |
| **高次元傾向スコア（hdPS）** | 大量の代理変数（診断コード・処方コード等）からPS推定（Schneeweiss et al., 2009） | 計算コスト大；代理変数の選択に恣意性；操作変数・衝突変数の混入リスク |

**既存手法の共通する限界**：いずれも「測定された変数による調整」が前提であり、**測定されていない変数によって形成される集団構造を検出・抽出する手法は確立されていない**。

### 1.4 本研究のストーリーライン：シミュレーション検証から実データ応用へ

本研究の最終目標は以下のパイプラインの確立である：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
最終目標：コヒーレント集団の抽出による正しい知見の獲得
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Step 1. 一般変数のみでデータを層別化する
        （測定変数の多変量パターンや予測力を利用）
                    ↓
  Step 2. 層＝コヒーレント集団の候補として扱う
        （各層内の均質性を評価）
                    ↓
  Step 3. 層内で分析を実施する
        （各コヒーレント集団内での正しい知見を得る）
                    ↓
  Step 4. コヒーレンス度指標を提示する
        （「これ以上分割する必要があるか」の判断基準）
                    ↓
  Step 5. 全体知見と部分知見の統合
        （シンプソンのパラドックスの回避・メタ分析的統合）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

この最終目標に向けて、本研究ではまず**シミュレーションによる原理的検証**を行う：

```
シミュレーション検証の論理：

  前提：重大変数Z（年齢・性別等）が既知のデータを生成する
        ↓
  操作：Zを「未測定」として扱い、一般変数Xのみで層別化する
        ↓
  問い：Xのみの層別化で、Zに基づく真の群構造を再現できるか？
        ↓
  もしYES → 「真に未測定の重大変数が存在する実データでも、
              一般変数だけで見えない群構造を検出・層別化できる」
              という手法の妥当性が支持される
        ↓
  実データ応用：Table 1 から均質性が明らかでない場合に
                サブ解析を推奨するための指標を提供する
```

### 1.5 本研究で検証する2つの仮説

- **仮説A（決定力残差仮説）**：一般変数からアウトカムへの予測力・予測残差のパターンが、未測定重大変数の影響を反映した構造を持ち、これによる層別化が真の群構造を再現する
- **仮説B（特徴量空間仮説）**：重大変数は一般変数の分布に系統的な影響を及ぼすため、一般変数の多変量パターンに「痕跡」が残り、アウトカム情報を使わずとも群構造を検出できる

## 2. データセット仕様

### 2.1 概要

シミュレーションにより、真の因果構造が既知のデータセットを生成する。重大変数Zは生成には使用するが、手法の入力からは意図的に除外する。

```
データセット構成:
├── 一般説明変数 X = {X1, X2, ..., X10}  （血液検査等を想定）
├── 重大説明変数 Z = {Z1, Z2, Z3}        （年齢・性別等を想定、「未測定」として扱う）
└── 被説明変数   Y                        （イベント発生 0/1）
```

### 2.2 変数の詳細定義

#### 2.2.1 重大変数 Z（意図的に「未測定」として扱う）

| 変数 | 想定 | 型 | 生成方法 |
|------|------|-----|----------|
| Z1 | 年齢 | 連続量 | N(60, 12²)、範囲 [20, 95] |
| Z2 | 性別 | 二値 | Bernoulli(0.5) |
| Z3 | BMI区分 | 順序(3水準) | Multinomial(0.3, 0.4, 0.3) |

#### 2.2.2 一般変数 X（「測定済み」として使用）

血液検査値を模擬。重大変数Zからの影響を受けるように生成する。

| 変数 | 想定 | Zからの影響度 |
|------|------|---------------|
| X1 | 血糖値(HbA1c) | Z1: 強, Z3: 強 |
| X2 | 総コレステロール | Z1: 中, Z2: 弱 |
| X3 | 収縮期血圧 | Z1: 強 |
| X4 | ALT | Z3: 中 |
| X5 | クレアチニン | Z1: 中, Z2: 弱 |
| X6 | ヘモグロビン | Z2: 強 |
| X7 | 白血球数 | Z1: 弱 |
| X8 | アルブミン | Z1: 中 |
| X9 | CRP | Z1: 弱, Z3: 弱 |
| X10 | 尿酸 | Z2: 中, Z3: 弱 |

#### 2.2.3 データ生成プロセス（因果DAG）

```
Z1(年齢) ──┬──→ X1, X2, X3, X5, X7, X8, X9  （一般変数への影響）
            ├──→ Y（アウトカムへの直接効果）
            └──→ X の一部を介した間接効果

Z2(性別) ──┬──→ X2, X5, X6, X10
            └──→ Y

Z3(BMI)  ──┬──→ X1, X4, X9, X10
            └──→ Y

X1..X10  ──────→ Y （一般変数の直接効果、ただしZより弱い）

ε (ノイズ) ────→ Y
```

#### 2.2.4 アウトカム生成モデル

```
logit(P(Y=1)) = β₀ 
               + β_Z1·Z1 + β_Z2·Z2 + β_Z3·Z3      # 重大変数の効果（大）
               + Σ β_Xi·Xi                            # 一般変数の効果（小〜中）
               + γ·(Z1×Z2)                            # 交互作用項（オプション）
               + ε
```

パラメータ設定の指針：
- 重大変数の効果サイズ：OR = 1.5〜3.0（臨床的に意味ある大きさ）
- 一般変数の効果サイズ：OR = 1.0〜1.3（弱〜中程度）
- イベント発生率：全体で10〜20%程度（典型的なコホート研究を想定）

### 2.3 サンプルサイズ

| シナリオ | N | 目的 |
|----------|---|------|
| 小規模 | 500 | 偶然変動の影響評価 |
| 中規模 | 2,000 | 主要検証 |
| 大規模 | 10,000 | 理論的限界の評価 |

### 2.4 シミュレーション反復

各シナリオについて 500〜1,000 回のモンテカルロシミュレーションを実施し、手法の安定性を評価する。

## 3. 手法1：一般変数から被説明変数への決定力による層別化（主手法）

### 3.1 概念と有望性

一般変数 X のみからアウトカム Y を予測するモデルを構築し、その「予測の確信度・予測残差の大きさ」によってデータを層別化する。

**キーアイデア**：X だけでは Y を十分に説明できない場合、予測残差が大きいサンプルは「X以外の未測定要因（= Z）の影響が大きいサンプル」である可能性が高い。この残差のパターンが系統的であれば、それは未測定の群構造を反映している。

**なぜ手法1（主手法）とするか**：
- **Y の情報を活用する分、ターゲットが明確**：「Xで説明できない部分 ≒ Zの痕跡」という論理が直接的
- **予後スコア（Hansen 2008）との理論的接続**が強く、先行研究に基づく正当化がしやすい
- **コヒーレンス度指標との親和性が高い**：予測残差の構造化度合い → コヒーレンス度の自然な定義に繋がる

### 3.2 予測モデルと決定力指標の候補

#### 方法1A：予測確率（Predicted Probability）ベース
```
手順:
1. X1〜X10 を説明変数、Y を被説明変数としたロジスティック回帰モデルを構築
2. 各サンプルの予測確率 p_hat を算出
3. p_hat の分位点でデータを層別化
   → 「一般変数で予測しやすいグループ」と「予測しにくいグループ」を分離
```

- **解釈**：予後スコア（Prognostic Score）と本質的に同じ概念。ただし「重大変数を意図的に除外」した状態で推定する点が独自
- **利点**：解釈性が高い、先行研究との接続が明確
- **懸念**：線形性の仮定；過学習の管理が必要

#### 方法1B：予測残差の絶対値ベース
```
手順:
1. 同上のモデルから予測確率 p_hat を得る
2. 残差 r = Y - p_hat を算出
3. |r| の大きさで層別化
   → 残差大群 = X では説明できない要因の影響が強い群
```

- **利点**：直観的にわかりやすい；「未説明部分」を直接的に切り出す
- **懸念**：二値アウトカムの残差分布が歪む；Y=1かつp_hat≈0のサンプルと、Y=0かつp_hat≈1のサンプルは質的に異なる可能性

#### 方法1C：交差検証型決定力スコア
```
手順:
1. データをK-fold に分割
2. 各foldについて、残りのfoldでモデルを学習し、holdout foldの予測確率を得る
3. 交差検証予測確率を「決定力スコア」として使用
4. 層別化に用いる
```

- **利点**：過学習の回避（パイロットデザイン（Aikens et al., 2020）の思想と共通）
- **懸念**：計算コスト増

#### 方法1D：機械学習モデルの不確実性ベース
```
手順:
1. X1〜X10 を入力としたRF / GBM / ニューラルネットでYを予測
2. モデル不確実性（RF: tree間の分散、NN: MCドロップアウトの分散）を算出
3. 不確実性の大きさで層別化
```

- **利点**：非線形な予測力の「行き詰まり」を捕捉
- **懸念**：モデルの不確実性 ≠ 入力変数の情報不足（アレアトリック vs エピステミック不確実性）の区別が必要

### 3.3 傾向スコア系手法との位置づけの違い

```
┌────────────────────────────────────────────────────────────┐
│                 本研究の手法1                                 │
│  一般変数 X ──→ Y の予測力で層別化                           │
│  （予後スコア型、ただし「重大変数を意図的に除外」した状態）     │
│                                                              │
│  vs.                                                         │
│                                                              │
│  傾向スコア法                                                 │
│  共変量 ──→ 治療割り付け確率で層別化                          │
│  （因果推論の文脈で治療効果の偏りなき推定が目的）              │
│                                                              │
│  vs.                                                         │
│                                                              │
│  予後スコア法（Hansen 2008; Aikens et al., 2020）             │
│  共変量 ──→ アウトカム予測確率で層別化                        │
│  （全共変量を使用する前提）                                    │
│                                                              │
│  本研究のユニークさ：                                         │
│    意図的にZを除外した上でX→Y予測を行い、                     │
│    その「限界」からZの存在を逆推定するのではなく、             │
│    ★「限界が示す群構造を利用して均質な部分集団を抽出する」★   │
└────────────────────────────────────────────────────────────┘
```

|------------|--------|------|

| 分割基準 | 等人数分割 / 等間隔分割 | |
| 予測モデル | ロジスティック回帰 / RF / GBM / NN | |
| CV fold数 | 5, 10 | 方法1Cで使用 |

## 4. 手法2：一般変数由来の特徴量得点による層別化（補完的手法）

### 4.1 概念

一般変数 X1〜X10 から多変量的な「特徴量得点」を算出し、この得点によってデータを層（stratum）に分割する。**Yの情報を一切使わない**ことが手法1との根本的な違い。

**補完的手法とする理由**：
- Yの情報を使わないため、ターゲットが間接的（Zの痕跡がXの共分散構造に残っていることを前提とする）
- ただし「Yに依存しない群構造の発見」として独自の価値がある：Yの定義が変わっても同じ層別化を使い回せる

### 4.2 特徴量得点の算出方法（候補）

#### 方法2A：主成分分析（PCA）ベース
```
手順:
1. X1〜X10 を標準化
2. PCA を実施し、第1〜第k主成分を抽出
3. 第1主成分得点（PC1）または複数主成分の重み付き合成得点を「特徴量得点」とする
4. 得点の分位点（四分位・五分位等）でデータを層別化
```

- **利点**：解釈が明快、計算が軽い
- **懸念**：PCAは分散最大方向を捉えるが、それが必ずしもZの影響方向と一致するとは限らない

**累積寄与率シナリオ**：臨床データでは変数間の相関が弱いことが多く、累積寄与率が高くならないケースが一般的。以下の複数シナリオを想定：

| シナリオ | 累積寄与率の閾値 | 想定される状況 | 備考 |
|----------|-----------------|---------------|------|
| **低寄与率** | 40% | 変数間の相関が弱い臨床データ。PC1〜2で40%程度しか説明できない | 多くの臨床研究で典型的 |
| **中寄与率** | 60% | 中程度の相関構造。PC1〜4程度で60%到達 | 比較的均質なデータ |
| **高寄与率** | 80% | 強い相関構造。PC1〜5程度で80%到達 | 理想的だが臨床では稀 |
| **固定次元** | k=1, 2, 3（次元数固定） | 寄与率閾値ではなく次元数で制御 | 寄与率に依らない比較用 |

さらに、寄与率の低さ自体が「Zの痕跡がXに残りにくい」ことを示唆する可能性がある。**累積寄与率と手法の有効性の関係**を検証項目に含める。

#### 方法2B：クラスタリングベース（k-means / 階層的クラスタリング）
```
手順:
1. X1〜X10 を標準化
2. k-means（k=3〜6）または階層的クラスタリングを実施
3. クラスタ帰属をそのまま「層」とする
```

- **利点**：非線形な構造も捉えうる
- **懸念**：クラスタ数kの選択に恣意性；高次元では距離ベースの手法が劣化する可能性

#### 方法2C：オートエンコーダ潜在表現ベース
```
手順:
1. X1〜X10 を入力とするオートエンコーダを訓練
2. ボトルネック層（2〜3次元）の潜在表現を得る
3. 潜在表現空間でクラスタリングまたは分位点分割
```

- **利点**：非線形な多様体構造を捉える能力が高い
- **懸念**：ブラックボックス性；ハイパーパラメータの影響大

#### 方法2D：ランダムフォレスト近接度（Proximity）ベース
```
手順:
1. X1〜X10 を特徴量として教師なしランダムフォレスト（合成データ法）を訓練
2. サンプル間の近接度行列を算出
3. 近接度行列に基づく多次元尺度法（MDS）またはクラスタリングで層別化
```

- **利点**：変数間の複雑な相互作用を暗黙的に捕捉
- **懸念**：計算コスト；結果の再現性

### 4.3 層別化の設定

| パラメータ | 候補値 | 備考 |
|------------|--------|------|
| 層数 | 3, 4, 5, 10 | 偶然変動とのトレードオフ |
| 分割基準 | 等人数分割 / 等間隔分割 | |
| PCA累積寄与率 | 40%, 60%, 80%, 固定次元(k=1,2,3) | 臨床実態を反映した複数シナリオ |
| 次元削減法 | PCA / AE / RF-Proximity | 各々の比較 |

## 5. 検証3：未測定重大変数による群構造の再現能力の評価

### 5.1 評価の枠組み

シミュレーションでは Z の真値が既知であるため、以下の問いを定量的に評価できる：

> **手法1・2で作成された「層（stratum）」は、Z によって定義される「真の群構造」とどの程度一致するか？**

ここでの一致は「代理指標としての検証」ではなく、**「未測定の重大変数が存在する状況で、一般変数のみから群構造を再現できるかの原理的証明」**である。

### 5.2 真の群構造の定義

重大変数 Z から真の群構造を以下のように定義する：

| 群構造の定義方法 | 詳細 |
|----------------|------|
| **離散化クラスタ** | Z1(年齢) を3区分 × Z2(性別) 2区分 × Z3(BMI) 3区分 = 最大18クラスタ |
| **Z空間クラスタリング** | Z1, Z2, Z3 の標準化空間で k-means（k を手法側の層数に合わせる） |
| **Z由来の予後リスク層** | Z のみからアウトカムを予測した予測確率の分位点による層 |

### 5.3 一致度の評価指標

#### (a) クラスタ一致度指標

| 指標 | 説明 | 適用場面 |
|------|------|----------|
| **Adjusted Rand Index (ARI)** | 偶然一致を補正したクラスタ一致度。[-1, 1]、1で完全一致 | クラスタ vs 層 |
| **Normalized Mutual Information (NMI)** | 情報理論ベースのクラスタ一致度。[0, 1] | クラスタ vs 層 |
| **V-measure** | 均質性(Homogeneity)と完全性(Completeness)の調和平均 | クラスタ vs 層 |

#### (b) 層内 Z 分布の均質性

| 指標 | 説明 |
|------|------|
| **層内 Z の分散比（ANOVA的）** | 層間分散 / 全分散。大きいほど層がZの情報を捕捉 |
| **層内 Z2(性別) のエントロピー** | 各層内の性別比が偏っているほどエントロピーが低い（= 層が性別を捕捉） |
| **η²（イータ二乗）** | 層を群変数、Zを従属変数としたときの効果量 |

#### (c) シンプソンのパラドックス解消度

| 指標 | 説明 |
|------|------|
| **方向一致率** | 全体効果とすべての層内効果の方向（正/負）が一致する割合 |
| **Cochran-Mantel-Haenszel検定** | 層別調整後の共通オッズ比と、未調整オッズ比の乖離 |

### 5.4 感度分析パラメータ

以下を変化させて手法の頑健性を評価：

| パラメータ | 変動範囲 | 目的 |
|------------|----------|------|
| Zの効果サイズ | OR 1.2〜5.0 | 重大変数の影響度に対する感度 |
| Z→X の影響経路の強さ | 相関 0.1〜0.7 | 間接的痕跡の濃さへの感度 |
| X→Y の直接効果の大きさ | OR 1.0〜2.0 | 一般変数自体の予測力への感度 |
| ノイズレベル | 低/中/高 | 偶然変動への頑健性 |
| Zの変数数 | 1, 2, 3 | 未測定変数の複雑さへの感度 |

### 5.5 コヒーレント集団抽出の評価

従来の「クラスタ一致度」に加え、本研究の最終目標に直結する評価軸を設ける：

#### (a) 層内コヒーレンスの評価

> **「抽出された各層は、内部的に均質な（コヒーレントな）集団として扱えるか？」**

この評価は、以下の3つの問題への対処を同時に検証する：
- **効果修飾の見落としの防止**：層間で効果が異なるなら、それは未検出の効果修飾が存在していたことを意味する
- **生態学的誤謬の緩和**：層内がコヒーレントであれば、集団レベルの知見≈個人レベルの知見となる
- **非崩壊性の影響最小化**：均質な層内での条件付き効果推定は、周辺効果との乖離を最小化する

| 指標 | 説明 | 意味 |
|------|------|------|
| **層内効果の同質性検定（Cochran's Q / I²）** | メタ分析の異質性指標を層間に適用。各層を「サブ研究」とみなす | I² が低い ≒ 層内がコヒーレント（効果修飾がない） |
| **層内 X→Y 関係の安定性** | 各層内で X→Y の回帰係数がどの程度一定か（係数の層間分散） | 低分散 ≒ 同質的なメカニズム（効果修飾なし） |
| **層内残差分布の形状** | 各層内の予測残差が正規分布に近いか（歪度・尖度・SW検定） | 正規に近い ≒ 系統的な未説明要因が少ない |
| **層間効果の方向・大きさの異質性** | 各層の効果推定値の方向（正/負）と大きさの分散 | 層間で効果の方向が反転 → 強い効果修飾の存在 |

#### (b) コヒーレンス度指標の定義（中核概念）

本研究のキーアウトプットの一つとして、**集団のコヒーレンス度を定量化する指標** C を提案する：

```
コヒーレンス度指標 C の候補定義：

  C₁（異質性ベース）:
     C₁ = 1 - I²(層間)
     I² は層間の効果推定値の異質性。C₁ ≈ 1 なら層間で効果が一致 → 全体がコヒーレント

  C₂（残差構造ベース）:
     C₂ = 1 - (層内残差の系統的成分 / 全残差分散)
     層内残差にパターンがなければ C₂ ≈ 1 → 層内がコヒーレント

  C₃（予測安定性ベース）:
     C₃ = 1 - CV(層別効果推定値のブートストラップ分散)
     層別化による効果推定値が安定しているほど C₃ が高い

  C₄（エントロピーベース）:
     C₄ = 1 - H(層内Z分布) / H_max
     層内のZ分布が偏っている（＝隠れた群変数を捕捉）ほど C₄ が高い
     （※シミュレーションでの検証用。実データではZが未知なので直接使えない）
```

**コヒーレンス度指標の活用イメージ**：

```
臨床研究者のワークフロー：

  1. Table 1 を作成する（従来の記述統計）
  2. 手法1 or 2 でデータを層別化する
  3. コヒーレンス度 C を算出する
  4. 判断：
     ┌─ C ≥ 閾値 → 全体を均質集団として分析してよい
     │             （これ以上サブグループを想定する必要なし）
     └─ C < 閾値 → ★サブ解析を推奨★
                    各層について個別に解析を実施し、
                    層間で結果が異なるかを確認すべき
```

**実データにおける適用条件**：C₁, C₂, C₃ はYとXのみから算出可能であり、Zの知識を必要としない。したがって実データに直接適用できる。C₄はシミュレーションでの手法検証用。

## 6. 検証4：疑似ランダム化の妥当性評価

### 6.1 「疑似ランダム化」の操作的定義

本研究における「疑似ランダム化が成立する」とは、以下を意味する：

> **手法1・2による層別化の後、各層内において Z の分布が（近似的に）均一化され、あたかもランダムに Z が割り当てられたかのような状態になること**

### 6.2 評価基準

#### (a) 共変量バランス指標（層内）

| 指標 | 説明 | 閾値の目安 |
|------|------|------------|
| **標準化平均差（SMD）** | 層内の Z の各水準間での共変量バランス | |SMD| < 0.1 で良好 |
| **分散比（Variance Ratio）** | 層内サブグループ間の分散の比 | 0.5〜2.0 の範囲で許容 |
| **KS統計量** | 連続変数の分布の全体的な類似度 | p > 0.05 |

#### (b) 因果効果推定の偏り

真の因果効果が既知（シミュレーション）であることを活かし：

| 指標 | 説明 |
|------|------|
| **バイアス** | E[θ_hat] - θ_true |
| **RMSE** | √(バイアス² + 分散) |
| **カバレッジ率** | 95%CIが真値を含む割合 |
| **シンプソンパラドックス発生率** | 層別後にパラドックスが解消される割合 |

#### (c) ベースライン手法との比較

本手法の妥当性を評価するために、以下のベースラインと比較する：

| 比較手法 | 説明 |
|----------|------|
| **無調整（Crude）** | 層別化なしの粗分析 |
| **真のZによる層別化（Oracle）** | Zを直接知っている場合の層別化（理論上の上限） |
| **傾向スコア層別化（PS）** | X を用いた傾向スコア（治療モデル型） |
| **完全な予後スコア層別化** | X + Z すべてを用いた予後スコア（実際は不可能だが上限として） |
| **ランダム層別化** | データをランダムに層に分割（下限ベースライン） |

#### (d) 偶然変動への対処の評価

| 評価項目 | 方法 |
|----------|------|
| **ブートストラップ安定性** | 1000回のブートストラップで層帰属の安定性を評価 |
| **層別化結果の再現性** | 異なるランダムシードで層割り当てがどの程度変動するか |
| **小サブグループの影響** | 層内サンプルサイズが小さい場合の推定量の分散増大を評価 |

### 6.3 疑似ランダム化とコヒーレント集団抽出の関係

疑似ランダム化とコヒーレント集団抽出は、同じ層別化操作の二つの側面である：

```
同じ層別化操作に対する二つの評価軸：

  層別化結果
    │
    ├── 疑似ランダム化の観点（検証4）
    │   「各層内でZがランダム化されているか？」
    │   → 層内でのZの均一性を評価
    │   → 均一 ≒ 各層が特定のZの組合せに対応するコヒーレント集団
    │
    ├── コヒーレント集団抽出の観点（検証3拡張）
    │   「各層は均質な部分集団として扱えるか？」
    │   → 層内での効果の同質性を評価
    │   → 同質 ≒ 層内でシンプソンのパラドックスが解消されている
    │
    └── バイアス緩和の観点（追加評価軸）
        「層別化により、効果修飾・生態学的誤謬・非崩壊性の問題が軽減されるか？」
        → 効果修飾：層間で効果が異なるなら、隠れた効果修飾が検出されたことを意味する
        → 生態学的誤謬：層内がコヒーレントなら、集団知見≈個人知見となり誤謬が緩和
        → 非崩壊性：均質層内の条件付きORは周辺効果との乖離が最小

  ★すべてが成立する場合：
    「未測定の重大変数によるコヒーレント集団を抽出でき、
     各集団内では偏りのない（疑似ランダム化された）分析が可能であり、
     効果修飾を検出し生態学的誤謬を回避した正しい知見を得られる」
    → 本研究の理想的な成功条件
```

## 8. 理論的考察（ブレインストーミング段階のメモ）

### 8.1 この手法が機能する条件（予想）

1. **Z→X の影響が十分に強い場合**：Z の「痕跡」がXの多変量空間に残るため、層別化がZの群構造と一致しやすい
2. **X の次元がZの次元より十分に大きい場合**：10次元のXから2〜3次元のZを逆推定するのは、自由度の観点から原理的に可能
3. **Zの効果が線形的に X に反映される場合**：PCAベースの手法が特に有効と予想
4. **Z間に交互作用がある場合**：非線形手法（AE、RF）が線形手法を上回ると予想

### 8.2 この手法が失敗する条件（予想）

1. **Z→X の影響が弱い場合**：Xの空間にZの情報がほぼ残らない
2. **X→Y の直接効果が支配的な場合**：手法1（決定力ベース）の残差にZの情報が含まれなくなる
3. **複数のZが相互に相殺する影響を持つ場合**：PCA等の線形手法では分離できない
4. **サンプルサイズが小さい場合**：偶然変動が層別化の精度を圧倒する

### 8.3 傾向スコア法との理論的関係

- **傾向スコア法**は「治療の割り付け確率」でバランシングする ← **背景変数から治療方向** へ向かう矢印をモデル化
- **手法1（決定力ベース）**は「アウトカムへの予測力」で層別化する ← **背景変数からアウトカム方向** へ向かう矢印をモデル化
- **手法2（特徴量得点ベース）**は背景変数間の相互関係自体で層別化する ← **因果構造から独立** な、純粋にデータ駆動型のアプローチ

手法2は因果推論の枠組みでは「無情報な層別化」と見做される可能性があるが、Zの痕跡がXに残るなら有効。これは **「近接因果推論（Proximal Causal Inference）」** の概念に関連する可能性がある（Xがunmeasured Zのproxy）。

### 8.4 コヒーレンス度指標の理論的基盤

コヒーレンス度指標は、以下の既存概念と理論的に接続する：

| 既存概念 | 本研究との対応 |
|----------|---------------|
| **メタ分析のI²統計量** | 層を「サブ研究」とみなし、効果の異質性をI²で評価 → C₁の基盤 |
| **混合モデルのクラス数選択（BIC/AIC）** | コヒーレント集団の「最適数」の決定にBIC的情報量基準を応用 |
| **潜在クラス分析（LCA）** | 観測変数から潜在クラスを推定する既存手法。本研究は「臨床的に解釈可能な層別化」を志向する点が異なる |
| **処理効果の異質性（HTE: Heterogeneous Treatment Effects）** | 因果推論における効果修飾の検出。本研究はHTEの「原因」としての群構造に着目 |
| **生態学的誤謬（Ecological Fallacy）** | 集団→個人への不適切な一般化。本研究はコヒーレント集団を抽出することで、集団知見≈個人知見となる状態を実現 |
| **非崩壊性（Non-collapsibility）** | 周辺効果≠条件付き効果となる数学的性質。均質層内の条件付き効果推定で乖離を最小化 |

**重要な理論的問い**：コヒーレンス度の閾値は普遍的に設定できるか、それともデータ特性に依存するか？ → Phase 2〜3で検証

### 8.5 本研究が対処するバイアス群の統合的理解

本研究のアプローチ（コヒーレント集団の抽出）が対処するバイアス・問題群は、互いに関連しつつも異なる概念である。その関係性を整理する：

```
本研究が対処するバイアス・問題の構造：

  根本原因：「研究対象集団が複数のコヒーレント集団を内包する」
    │
    ├─→ 交絡バイアス：隠れた群構造が曝露とアウトカムの両方に関連
    ├─→ シンプソンのパラドックス：集団全体の効果が部分集団で逆転
    ├─→ 効果修飾の見落とし：効果が真に異なるのに「平均」を報告
    ├─→ 生態学的誤謬：集団知見を個人に不適切に適用
    └─→ 非崩壊性の影響：周辺効果≠条件付き効果となる乖離
            │
            ↓
  対処：「コヒーレント集団を抽出し、各集団内で分析する」
    │
    ├─→ 交絡：層内でZが均一化 → 交絡バイアスが軽減
    ├─→ シンプソン：層内で効果の方向が一貫 → パラドックスが解消
    ├─→ 効果修飾：層間の効果差が明示的に検出可能
    ├─→ 生態学的誤謬：コヒーレント層内なら集団知見≈個人知見
    └─→ 非崩壊性：均質層内の条件付き効果で乖離最小化
```

このように、本研究のアプローチは「隠れた群構造が存在する」という単一の根本原因に対処することで、複数のバイアス・問題を同時に緩和する可能性を持つ。

### 8.6 偶然変動への対処の方針

| 戦略 | 内容 |
|------|------|
| **正則化** | 特徴量得点算出時にリッジ/LASSO正則化 |
| **クロスバリデーション** | 層別化スコアの算出にCV型パイロットデザインを採用 |

## Appendix B: Glossary

| Terms | Definitions |
|------|------|
| Confounder | Variables that causally influence both exposure and outcome |
| Simpson's Paradox | A statistical phenomenon in which the overall association is reversed in subgroups |
| Propensity Score | Probability of treatment assignment given observed covariates |
| Prognostic Score | Predictive value of predicting outcome from covariates (Hansen 2008) |
| High-dimensional propensity score (hdPS) | Propensity score that empirically selects and estimates covariates from a large number of proxy variables (Schneeweiss et al., 2009) |
| Disease Risk Score (DRS) | Outcome prediction score estimated from unexposed group only |
| Proximal Causal Inference | Causal inference framework using proxy variables for unmeasured confounding |
| **Coherent population** | A subpopulation that is internally homogeneous and the knowledge of the entire population can be applied to each individual |
| **Degree of coherence** | Quantitative index showing how coherent (internally homogeneous) a group is (proposed in this study) |
| **Incoherent population** | A population that contains multiple coherent populations and the overall knowledge may not be applicable to subpopulations |
| ARI (Adjusted Rand Index) | Cluster concordance index corrected for coincidence |
| NMI (Normalized Mutual Information) | Information theory-based cluster concordance index |
| DAG (Directed Acyclic Graph) | Directed acyclic graph that expresses causal structure |
| Pilot design | Research design in which design information is obtained from part of the data (pilot set) and analysis is performed using the rest |
| I² statistic | Indicator of heterogeneity of effect estimates in meta-analysis (0-100%) |
| **Effect Modification** | A phenomenon in which the effect of exposure truly differs depending on the level of a third variable. Unlike confounding, the “effect itself” is different |
| **Ecological Fallacy** | The fallacy of inappropriately generalizing group-level associations to the individual level. Related to Simpson's paradox, but the direction of inference is different |
| **Non-collapsibility** | Mathematical property of effect indicators such as OR such that marginal effects ≠ conditional effects even without confounding |
