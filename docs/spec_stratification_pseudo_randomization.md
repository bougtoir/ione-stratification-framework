## 1. 背景と問題意識

### 1.1 過去起点コホート研究における根本的課題

過去起点（後ろ向き）コホート研究では、曝露割り付けが研究者の制御下にないため、以下のバイアスが不可避的に発生する：

- **交絡バイアス（Confounding Bias）**：曝露と結果の両方に影響する第三の変数が、見かけ上の因果関係を生み出す
- **シンプソンのパラドックス**：集団全体で観察される関連の方向が、サブグループに分割すると逆転する現象。交絡の一特殊形態として理解できるが、必ずしも交絡のみに起因するわけではない（Simpson's paradox beyond confounding, 2024）
- **偶然変動（Random Fluctuation）**：有限サンプルに起因するランダムな誤差が、特にサブグループ解析において効果推定値を不安定にする

### 1.2 既存の疑似ランダム化手法とその限界

| 手法 | 原理 | 主な限界 |
|------|------|----------|
| **傾向スコア（Propensity Score; PS）** | 観察された共変量から治療割り付け確率を推定し、同スコアで層別化・マッチング | 未測定交絡の調整不可；治療割り付けモデルの正確性に依存 |
| **予後スコア（Prognostic Score）** | 共変量からアウトカムリスクを推定し層別化に使用（Aikens et al., 2020; stratamatch） | 未測定交絡の直接調整は不可；ただし感度分析のパワーが向上 |
| **疾患リスクスコア（Disease Risk Score; DRS）** | 非曝露群のみでアウトカム予測モデルを構築 | PS同様、未測定交絡に脆弱 |
| **操作変数法（Instrumental Variables; IV）** | 治療には影響するがアウトカムには直接影響しない変数を利用 | 適切なIVの入手が困難；弱い道具変数問題 |
| **高次元傾向スコア（hdPS）** | 大量の代理変数からPS推定（Wyss et al., 2022） | 計算コスト大；代理変数の選択に恣意性 |

### 1.3 本研究の着眼点：「一般変数の残余パターン」から未測定変数を逆推定する

既存手法の多くは「測定された変数による直接調整」を志向するが、本研究は発想を転換し：

> **一般変数（血液検査等）から構成される特徴量空間のパターン（得点・決定力）が、意図的に除外した重大変数（年齢・性別等）の代理指標として機能しうるか**

を検証する。これは以下の仮説に基づく：

- **仮説A（特徴量空間仮説）**：重大変数は一般変数の分布に系統的な影響を及ぼすため、一般変数の多変量パターンに「痕跡」が残る
- **仮説B（決定力残差仮説）**：一般変数からアウトカムへの予測残差が、未測定重大変数の影響を反映した構造を持つ

## 2. データセット仕様

### 2.1 概要

シミュレーションにより、真の因果構造が既知のデータセットを生成する。

```
データセット構成:
├── 一般説明変数 X = {X1, X2, ..., X10}  （血液検査等を想定）
├── 重大説明変数 Z = {Z1, Z2, Z3}        （年齢・性別等を想定）
└── 被説明変数   Y                        （イベント発生 0/1）
```

### 2.2 変数の詳細定義

#### 2.2.1 重大変数 Z（意図的に「未測定」として扱う）

| 変数 | 想定 | 型 | 生成方法 |
|------|------|-----|----------|
| Z1 | 年齢 | 連続量 | N(60, 12²)、範囲 [20, 95] |
| Z2 | 性別 | 二値 | Bernoulli(0.5) |
| Z3 | BMI区分 | 順序(3水準) | Multinomial(0.3, 0.4, 0.3) |

#### 2.2.2 一般変数 X（「測定済み」として使用）

血液検査値を模擬。重大変数Zからの影響を受けるように生成する。

| 変数 | 想定 | Zからの影響度 |
|------|------|---------------|
| X1 | 血糖値(HbA1c) | Z1: 強, Z3: 強 |
| X2 | 総コレステロール | Z1: 中, Z2: 弱 |
| X3 | 収縮期血圧 | Z1: 強 |
| X4 | ALT | Z3: 中 |
| X5 | クレアチニン | Z1: 中, Z2: 弱 |
| X6 | ヘモグロビン | Z2: 強 |
| X7 | 白血球数 | Z1: 弱 |
| X8 | アルブミン | Z1: 中 |
| X9 | CRP | Z1: 弱, Z3: 弱 |
| X10 | 尿酸 | Z2: 中, Z3: 弱 |

#### 2.2.3 データ生成プロセス（因果DAG）

```
Z1(年齢) ──┬──→ X1, X2, X3, X5, X7, X8, X9  （一般変数への影響）
            ├──→ Y（アウトカムへの直接効果）
            └──→ X の一部を介した間接効果

Z2(性別) ──┬──→ X2, X5, X6, X10
            └──→ Y

Z3(BMI)  ──┬──→ X1, X4, X9, X10
            └──→ Y

X1..X10  ──────→ Y （一般変数の直接効果、ただしZより弱い）

ε (ノイズ) ────→ Y
```

#### 2.2.4 アウトカム生成モデル

```
logit(P(Y=1)) = β₀ 
               + β_Z1·Z1 + β_Z2·Z2 + β_Z3·Z3      # 重大変数の効果（大）
               + Σ β_Xi·Xi                            # 一般変数の効果（小〜中）
               + γ·(Z1×Z2)                            # 交互作用項（オプション）
               + ε
```

パラメータ設定の指針：
- 重大変数の効果サイズ：OR = 1.5〜3.0（臨床的に意味ある大きさ）
- 一般変数の効果サイズ：OR = 1.0〜1.3（弱〜中程度）
- イベント発生率：全体で10〜20%程度（典型的なコホート研究を想定）

### 2.3 サンプルサイズ

| シナリオ | N | 目的 |
|----------|---|------|
| 小規模 | 500 | 偶然変動の影響評価 |
| 中規模 | 2,000 | 主要検証 |
| 大規模 | 10,000 | 理論的限界の評価 |

### 2.4 シミュレーション反復

各シナリオについて 500〜1,000 回のモンテカルロシミュレーションを実施し、手法の安定性を評価する。

## 3. 手法1：一般変数由来の特徴量得点による層別化

### 3.1 概念

一般変数 X1〜X10 から多変量的な「特徴量得点」を算出し、この得点によってデータを層（stratum）に分割する。Zの情報を一切使わずに層を構成することがポイント。

### 3.2 特徴量得点の算出方法（候補）

#### 方法1A：主成分分析（PCA）ベース
```
手順:
1. X1〜X10 を標準化
2. PCA を実施し、第1〜第k主成分を抽出（累積寄与率80%等）
3. 第1主成分得点（PC1）または複数主成分の重み付き合成得点を「特徴量得点」とする
4. 得点の分位点（四分位・五分位等）でデータを層別化
```

- **利点**：解釈が明快、計算が軽い
- **懸念**：PCAは分散最大方向を捉えるが、それが必ずしもZの影響方向と一致するとは限らない

#### 方法1B：クラスタリングベース（k-means / 階層的クラスタリング）
```
手順:
1. X1〜X10 を標準化
2. k-means（k=3〜6）または階層的クラスタリングを実施
3. クラスタ帰属をそのまま「層」とする
```

- **利点**：非線形な構造も捉えうる
- **懸念**：クラスタ数kの選択に恣意性；高次元では距離ベースの手法が劣化する可能性

#### 方法1C：オートエンコーダ潜在表現ベース
```
手順:
1. X1〜X10 を入力とするオートエンコーダを訓練
2. ボトルネック層（2〜3次元）の潜在表現を得る
3. 潜在表現空間でクラスタリングまたは分位点分割
```

- **利点**：非線形な多様体構造を捉える能力が高い
- **懸念**：ブラックボックス性；ハイパーパラメータの影響大

#### 方法1D：ランダムフォレスト近接度（Proximity）ベース
```
手順:
1. X1〜X10 を特徴量として教師なしランダムフォレスト（合成データ法）を訓練
2. サンプル間の近接度行列を算出
3. 近接度行列に基づく多次元尺度法（MDS）またはクラスタリングで層別化
```

- **利点**：変数間の複雑な相互作用を暗黙的に捕捉
- **懸念**：計算コスト；結果の再現性

### 3.3 層別化の設定

| パラメータ | 候補値 | 備考 |
|------------|--------|------|
| 層数 | 3, 4, 5, 10 | 偶然変動とのトレードオフ |
| 分割基準 | 等人数分割 / 等間隔分割 | |
| 次元削減法 | PCA / AE / RF-Proximity | 各々の比較 |

## 4. 手法2：一般変数から被説明変数への決定力による層別化

### 4.1 概念

一般変数 X のみからアウトカム Y を予測するモデルを構築し、その「予測の確信度・予測残差の大きさ」によってデータを層別化する。

**キーアイデア**：X だけでは Y を十分に説明できない場合、予測残差が大きいサンプルは「X以外の未測定要因（= Z）の影響が大きいサンプル」である可能性が高い。

### 4.2 予測モデルと決定力指標の候補

#### 方法2A：予測確率（Predicted Probability）ベース
```
手順:
1. X1〜X10 を説明変数、Y を被説明変数としたロジスティック回帰モデルを構築
2. 各サンプルの予測確率 p_hat を算出
3. p_hat の分位点でデータを層別化
   → 「一般変数で予測しやすいグループ」と「予測しにくいグループ」を分離
```

- **解釈**：予後スコア（Prognostic Score）と本質的に同じ概念

#### 方法2B：予測残差の絶対値ベース
```
手順:
1. 同上のモデルから予測確率 p_hat を得る
2. 残差 r = Y - p_hat を算出
3. |r| の大きさで層別化
   → 残差大群 = X では説明できない要因の影響が強い群
```

- **利点**：直観的にわかりやすい；「未説明部分」を直接的に切り出す
- **懸念**：二値アウトカムの残差分布が歪む；Y=1かつp_hat≈0のサンプルと、Y=0かつp_hat≈1のサンプルは質的に異なる可能性

#### 方法2C：交差検証型決定力スコア
```
手順:
1. データをK-fold に分割
2. 各foldについて、残りのfoldでモデルを学習し、holdout foldの予測確率を得る
3. 交差検証予測確率を「決定力スコア」として使用
4. 層別化に用いる
```

- **利点**：過学習の回避（パイロットデザインの思想と共通; Aikens et al., 2020）
- **懸念**：計算コスト増

#### 方法2D：機械学習モデルの不確実性ベース
```
手順:
1. X1〜X10 を入力としたRF / GBM / ニューラルネットでYを予測
2. モデル不確実性（RF: tree間の分散、NN: MCドロップアウトの分散）を算出
3. 不確実性の大きさで層別化
```

- **利点**：非線形な予測力の「行き詰まり」を捕捉
- **懸念**：モデルの不確実性 ≠ 入力変数の情報不足（アレアトリック vs エピステミック）の区別が必要

### 4.3 傾向スコア系手法との位置づけの違い

```
┌────────────────────────────────────────────────────────────┐
│                 本研究の手法2                                 │
│  一般変数 X ──→ Y の予測力で層別化                           │
│  （予後スコア型、ただし「重大変数を意図的に除外」した状態）     │
│                                                              │
│  vs.                                                         │
│                                                              │
│  傾向スコア法                                                 │
│  共変量 ──→ 治療割り付け確率で層別化                          │
│  （因果推論の文脈で治療効果の偏りなき推定が目的）              │
│                                                              │
│  vs.                                                         │
│                                                              │
│  予後スコア法（Stuart et al., 2013; Aikens et al., 2020）     │
│  共変量 ──→ アウトカム予測確率で層別化                        │
│  （全共変量を使用する前提）                                    │
└────────────────────────────────────────────────────────────┘
```

**本研究のユニークさ**：意図的に重大変数Zを除外した上で X→Y 予測を行い、その「限界」から Z の存在を逆推定しようとする点。

## 5. 検証3：未測定重大変数のあぶり出し能力の評価

### 5.1 評価の枠組み

シミュレーションでは Z の真値が既知であるため、以下の問いを定量的に評価できる：

> **手法1・2で作成された「層（stratum）」は、Z によって定義される「真のクラスタ」とどの程度一致するか？**

### 5.2 真のクラスタの定義

重大変数 Z から真のクラスタを以下のように定義する：

| クラスタリング方法 | 詳細 |
|-------------------|------|
| **離散化クラスタ** | Z1(年齢) を3区分 × Z2(性別) 2区分 × Z3(BMI) 3区分 = 最大18クラスタ |
| **Z空間クラスタリング** | Z1, Z2, Z3 の標準化空間で k-means（k を真クラスタ数に合わせる） |
| **Z由来の予後リスク層** | Z のみからアウトカムを予測した予測確率の分位点による層 |

### 5.3 一致度の評価指標

#### (a) クラスタ一致度指標

| 指標 | 説明 | 適用場面 |
|------|------|----------|
| **Adjusted Rand Index (ARI)** | 偶然一致を補正したクラスタ一致度。[-1, 1]、1で完全一致 | クラスタ vs 層 |
| **Normalized Mutual Information (NMI)** | 情報理論ベースのクラスタ一致度。[0, 1] | クラスタ vs 層 |
| **V-measure** | 均質性(Homogeneity)と完全性(Completeness)の調和平均 | クラスタ vs 層 |

#### (b) 層内 Z 分布の均質性

| 指標 | 説明 |
|------|------|
| **層内 Z の分散比（ANOVA的）** | 層間分散 / 全分散。大きいほど層がZの情報を捕捉 |
| **層内 Z2(性別) のエントロピー** | 各層内の性別比が偏っているほどエントロピーが低い（= 層が性別を捕捉） |
| **η²（イータ二乗）** | 層を群変数、Zを従属変数としたときの効果量 |

#### (c) シンプソンのパラドックス解消度

| 指標 | 説明 |
|------|------|
| **方向一致率** | 全体効果とすべての層内効果の方向（正/負）が一致する割合 |
| **Cochran-Mantel-Haenszel検定** | 層別調整後の共通オッズ比と、未調整オッズ比の乖離 |

### 5.4 感度分析パラメータ

以下を変化させて手法の頑健性を評価：

| パラメータ | 変動範囲 | 目的 |
|------------|----------|------|
| Zの効果サイズ | OR 1.2〜5.0 | 重大変数の影響度に対する感度 |
| Z→X の影響経路の強さ | 相関 0.1〜0.7 | 間接的痕跡の濃さへの感度 |
| X→Y の直接効果の大きさ | OR 1.0〜2.0 | 一般変数自体の予測力への感度 |
| ノイズレベル | 低/中/高 | 偶然変動への頑健性 |
| Zの変数数 | 1, 2, 3 | 未測定変数の複雑さへの感度 |

## 6. 検証4：疑似ランダム化の妥当性評価

### 6.1 「疑似ランダム化」の操作的定義

本研究における「疑似ランダム化が成立する」とは、以下を意味する：

> **手法1・2による層別化の後、各層内において Z の分布が（近似的に）均一化され、あたかもランダムに Z が割り当てられたかのような状態になること**

### 6.2 評価基準

#### (a) 共変量バランス指標（層内）

| 指標 | 説明 | 閾値の目安 |
|------|------|------------|
| **標準化平均差（SMD）** | 層内の Z の各水準間での共変量バランス | |SMD| < 0.1 で良好 |
| **分散比（Variance Ratio）** | 層内サブグループ間の分散の比 | 0.5〜2.0 の範囲で許容 |
| **KS統計量** | 連続変数の分布の全体的な類似度 | p > 0.05 |

#### (b) 因果効果推定の偏り

真の因果効果が既知（シミュレーション）であることを活かし：

| 指標 | 説明 |
|------|------|
| **バイアス** | E[θ_hat] - θ_true |
| **RMSE** | √(バイアス² + 分散) |
| **カバレッジ率** | 95%CIが真値を含む割合 |
| **シンプソンパラドックス発生率** | 層別後にパラドックスが解消される割合 |

#### (c) ベースライン手法との比較

本手法の妥当性を評価するために、以下のベースラインと比較する：

| 比較手法 | 説明 |
|----------|------|
| **無調整（Crude）** | 層別化なしの粗分析 |
| **真のZによる層別化（Oracle）** | Zを直接知っている場合の層別化（理論上の上限） |
| **傾向スコア層別化（PS）** | X を用いた傾向スコア（治療モデル型） |
| **完全な予後スコア層別化** | X + Z すべてを用いた予後スコア（実際は不可能だが上限として） |
| **ランダム層別化** | データをランダムに層に分割（下限ベースライン） |

#### (d) 偶然変動への対処の評価

| 評価項目 | 方法 |
|----------|------|
| **ブートストラップ安定性** | 1000回のブートストラップで層帰属の安定性を評価 |
| **層別化結果の再現性** | 異なるランダムシードで層割り当てがどの程度変動するか |
| **小サブグループの影響** | 層内サンプルサイズが小さい場合の推定量の分散増大を評価 |

## 7. 実験計画の全体像

### 7.1 実験マトリクス

```
サンプルサイズ (3) × 手法 (1A,1B,1C,1D,2A,2B,2C,2D) × 層数 (4)
× Zの効果サイズ (4) × Z→X影響強度 (4) × シミュレーション反復 (500)
= 約 384,000 シミュレーション条件（大規模だが段階的に実施）
```

### 7.2 段階的実施計画

| フェーズ | 内容 | 目的 |
|----------|------|------|
| **Phase 0** | データ生成コードの実装と検証 | 因果DAGの正確な実装 |
| **Phase 1** | 中規模(N=2000)、代表的パラメータで手法1A・2A のみ | 概念実証（Proof of Concept） |
| **Phase 2** | Phase 1 の結果を踏まえ手法候補を絞り込み | 有望な手法の特定 |
| **Phase 3** | 全サンプルサイズ × 有望手法 × 感度パラメータの網羅的評価 | 包括的検証 |
| **Phase 4** | 実データ（公開データセット等）への適用 | 外的妥当性の確認 |

| 出力 | 内容 |
|------|------|
| **ヒートマップ** | ARI/NMI を手法×パラメータ設定で可視化 |

| **ROC的曲線** | Z クラスタの検出力を「層数」をパラメータとして描画 |
| **シンプソンパラドックス解消図** | 全体効果 vs 層別効果の方向を視覚化（Ecological fallacy illustration） |
| **層内Zの分布図** | 各層におけるZ1(年齢)・Z2(性別)の分布をバイオリンプロットで表示 |

## 8. 理論的考察（ブレインストーミング段階のメモ）

### 8.1 この手法が機能する条件（予想）

1. **Z→X の影響が十分に強い場合**：Z の「痕跡」がXの多変量空間に残るため、層別化がZのクラスタと一致しやすい
2. **X の次元がZの次元より十分に大きい場合**：10次元のXから2〜3次元のZを逆推定するのは、自由度の観点から原理的に可能
3. **Zの効果が線形的に X に反映される場合**：PCAベースの手法が特に有効と予想
4. **Z間に交互作用がある場合**：非線形手法（AE、RF）が線形手法を上回ると予想

### 8.2 この手法が失敗する条件（予想）

1. **Z→X の影響が弱い場合**：Xの空間にZの情報がほぼ残らない
2. **X→Y の直接効果が支配的な場合**：手法2（決定力ベース）の残差にZの情報が含まれなくなる
3. **複数のZが相互に相殺する影響を持つ場合**：PCA等の線形手法では分離できない
4. **サンプルサイズが小さい場合**：偶然変動が層別化の精度を圧倒する

### 8.3 傾向スコア法との理論的関係

- **傾向スコア法**は「治療の割り付け確率」でバランシングする ← **背景変数から治療方向** へ向かう矢印をモデル化
- **手法2（決定力ベース）**は「アウトカムへの予測力」で層別化する ← **背景変数からアウトカム方向** へ向かう矢印をモデル化
- **手法1（特徴量得点ベース）**は背景変数間の相互関係自体で層別化する ← **因果構造から独立** な、純粋にデータ駆動型のアプローチ

手法1は因果推論の枠組みでは「無情報な層別化」と見做される可能性があるが、Zの痕跡がXに残るなら有効。これは **「近接因果推論（Proximal Causal Inference）」** の概念に関連する可能性がある（Xがunmeasured Zのproxy）。

### 8.4 偶然変動への対処の方針

| 戦略 | 内容 |
|------|------|
| **正則化** | 特徴量得点算出時にリッジ/LASSO正則化 |
| **クロスバリデーション** | 層別化スコアの算出にCV型パイロットデザインを採用 |
| **ブートストラップ集約** | 複数回の層別化結果を集約（Bagging of stratification） |
| **層の最小サンプルサイズ制約** | 各層に最低n人を確保する制約条件 |
| **ペナルティ付きクラスタリング** | 極端に小さいクラスタを抑制 |

## 1. 背景と問題意識

### 1.1 過去起点コホート研究における根本的課題

過去起点（後ろ向き）コホート研究では、曝露割り付けが研究者の制御下にないため、以下のバイアスが不可避的に発生する：

- **交絡バイアス（Confounding Bias）**：曝露と結果の両方に影響する第三の変数が、見かけ上の因果関係を生み出す
- **シンプソンのパラドックス**：集団全体で観察される関連の方向が、サブグループに分割すると逆転する現象。交絡の一特殊形態として理解できるが、必ずしも交絡のみに起因するわけではない（Simpson's paradox beyond confounding, 2024）
- **偶然変動（Random Fluctuation）**：有限サンプルに起因するランダムな誤差が、特にサブグループ解析において効果推定値を不安定にする

### 1.2 既存の疑似ランダム化手法とその限界

| 手法 | 原理 | 主な限界 |
|------|------|----------|
| **傾向スコア（Propensity Score; PS）** | 観察された共変量から治療割り付け確率を推定し、同スコアで層別化・マッチング | 未測定交絡の調整不可；治療割り付けモデルの正確性に依存 |
| **予後スコア（Prognostic Score）** | 共変量からアウトカムリスクを推定し層別化に使用（Aikens et al., 2020; stratamatch） | 未測定交絡の直接調整は不可；ただし感度分析のパワーが向上 |
| **疾患リスクスコア（Disease Risk Score; DRS）** | 非曝露群のみでアウトカム予測モデルを構築 | PS同様、未測定交絡に脆弱 |
| **操作変数法（Instrumental Variables; IV）** | 治療には影響するがアウトカムには直接影響しない変数を利用 | 適切なIVの入手が困難；弱い道具変数問題 |
| **高次元傾向スコア（hdPS）** | 大量の代理変数からPS推定（Wyss et al., 2022） | 計算コスト大；代理変数の選択に恣意性 |

### 1.3 本研究の着眼点：「一般変数の残余パターン」から未測定変数を逆推定する

既存手法の多くは「測定された変数による直接調整」を志向するが、本研究は発想を転換し：

> **一般変数（血液検査等）から構成される特徴量空間のパターン（得点・決定力）が、意図的に除外した重大変数（年齢・性別等）の代理指標として機能しうるか**

を検証する。これは以下の仮説に基づく：

- **仮説A（特徴量空間仮説）**：重大変数は一般変数の分布に系統的な影響を及ぼすため、一般変数の多変量パターンに「痕跡」が残る
- **仮説B（決定力残差仮説）**：一般変数からアウトカムへの予測残差が、未測定重大変数の影響を反映した構造を持つ

## 2. データセット仕様

### 2.1 概要

シミュレーションにより、真の因果構造が既知のデータセットを生成する。

```
データセット構成:
├── 一般説明変数 X = {X1, X2, ..., X10}  （血液検査等を想定）
├── 重大説明変数 Z = {Z1, Z2, Z3}        （年齢・性別等を想定）
└── 被説明変数   Y                        （イベント発生 0/1）
```

### 2.2 変数の詳細定義

#### 2.2.1 重大変数 Z（意図的に「未測定」として扱う）

| 変数 | 想定 | 型 | 生成方法 |
|------|------|-----|----------|
| Z1 | 年齢 | 連続量 | N(60, 12²)、範囲 [20, 95] |
| Z2 | 性別 | 二値 | Bernoulli(0.5) |
| Z3 | BMI区分 | 順序(3水準) | Multinomial(0.3, 0.4, 0.3) |

#### 2.2.2 一般変数 X（「測定済み」として使用）

血液検査値を模擬。重大変数Zからの影響を受けるように生成する。

| 変数 | 想定 | Zからの影響度 |
|------|------|---------------|
| X1 | 血糖値(HbA1c) | Z1: 強, Z3: 強 |
| X2 | 総コレステロール | Z1: 中, Z2: 弱 |
| X3 | 収縮期血圧 | Z1: 強 |
| X4 | ALT | Z3: 中 |
| X5 | クレアチニン | Z1: 中, Z2: 弱 |
| X6 | ヘモグロビン | Z2: 強 |
| X7 | 白血球数 | Z1: 弱 |
| X8 | アルブミン | Z1: 中 |
| X9 | CRP | Z1: 弱, Z3: 弱 |
| X10 | 尿酸 | Z2: 中, Z3: 弱 |

#### 2.2.3 データ生成プロセス（因果DAG）

```
Z1(年齢) ──┬──→ X1, X2, X3, X5, X7, X8, X9  （一般変数への影響）
            ├──→ Y（アウトカムへの直接効果）
            └──→ X の一部を介した間接効果

Z2(性別) ──┬──→ X2, X5, X6, X10
            └──→ Y

Z3(BMI)  ──┬──→ X1, X4, X9, X10
            └──→ Y

X1..X10  ──────→ Y （一般変数の直接効果、ただしZより弱い）

ε (ノイズ) ────→ Y
```

#### 2.2.4 アウトカム生成モデル

```
logit(P(Y=1)) = β₀ 
               + β_Z1·Z1 + β_Z2·Z2 + β_Z3·Z3      # 重大変数の効果（大）
               + Σ β_Xi·Xi                            # 一般変数の効果（小〜中）
               + γ·(Z1×Z2)                            # 交互作用項（オプション）
               + ε
```

パラメータ設定の指針：
- 重大変数の効果サイズ：OR = 1.5〜3.0（臨床的に意味ある大きさ）
- 一般変数の効果サイズ：OR = 1.0〜1.3（弱〜中程度）
- イベント発生率：全体で10〜20%程度（典型的なコホート研究を想定）

### 2.3 サンプルサイズ

| シナリオ | N | 目的 |
|----------|---|------|
| 小規模 | 500 | 偶然変動の影響評価 |
| 中規模 | 2,000 | 主要検証 |
| 大規模 | 10,000 | 理論的限界の評価 |

### 2.4 シミュレーション反復

各シナリオについて 500〜1,000 回のモンテカルロシミュレーションを実施し、手法の安定性を評価する。

## 3. 手法1：一般変数由来の特徴量得点による層別化

### 3.1 概念

一般変数 X1〜X10 から多変量的な「特徴量得点」を算出し、この得点によってデータを層（stratum）に分割する。Zの情報を一切使わずに層を構成することがポイント。

### 3.2 特徴量得点の算出方法（候補）

#### 方法1A：主成分分析（PCA）ベース
```
手順:
1. X1〜X10 を標準化
2. PCA を実施し、第1〜第k主成分を抽出（累積寄与率80%等）
3. 第1主成分得点（PC1）または複数主成分の重み付き合成得点を「特徴量得点」とする
4. 得点の分位点（四分位・五分位等）でデータを層別化
```

- **利点**：解釈が明快、計算が軽い
- **懸念**：PCAは分散最大方向を捉えるが、それが必ずしもZの影響方向と一致するとは限らない

#### 方法1B：クラスタリングベース（k-means / 階層的クラスタリング）
```
手順:
1. X1〜X10 を標準化
2. k-means（k=3〜6）または階層的クラスタリングを実施
3. クラスタ帰属をそのまま「層」とする
```

- **利点**：非線形な構造も捉えうる
- **懸念**：クラスタ数kの選択に恣意性；高次元では距離ベースの手法が劣化する可能性

#### 方法1C：オートエンコーダ潜在表現ベース
```
手順:
1. X1〜X10 を入力とするオートエンコーダを訓練
2. ボトルネック層（2〜3次元）の潜在表現を得る
3. 潜在表現空間でクラスタリングまたは分位点分割
```

- **利点**：非線形な多様体構造を捉える能力が高い
- **懸念**：ブラックボックス性；ハイパーパラメータの影響大

#### 方法1D：ランダムフォレスト近接度（Proximity）ベース
```
手順:
1. X1〜X10 を特徴量として教師なしランダムフォレスト（合成データ法）を訓練
2. サンプル間の近接度行列を算出
3. 近接度行列に基づく多次元尺度法（MDS）またはクラスタリングで層別化
```

- **利点**：変数間の複雑な相互作用を暗黙的に捕捉
- **懸念**：計算コスト；結果の再現性

### 3.3 層別化の設定

| パラメータ | 候補値 | 備考 |
|------------|--------|------|
| 層数 | 3, 4, 5, 10 | 偶然変動とのトレードオフ |
| 分割基準 | 等人数分割 / 等間隔分割 | |
| 次元削減法 | PCA / AE / RF-Proximity | 各々の比較 |

---

## 4. 手法2：一般変数から被説明変数への決定力による層別化

### 4.1 概念

一般変数 X のみからアウトカム Y を予測するモデルを構築し、その「予測の確信度・予測残差の大きさ」によってデータを層別化する。

**キーアイデア**：X だけでは Y を十分に説明できない場合、予測残差が大きいサンプルは「X以外の未測定要因（= Z）の影響が大きいサンプル」である可能性が高い。

### 4.2 予測モデルと決定力指標の候補

#### 方法2A：予測確率（Predicted Probability）ベース
```
手順:
1. X1〜X10 を説明変数、Y を被説明変数としたロジスティック回帰モデルを構築
2. 各サンプルの予測確率 p_hat を算出
3. p_hat の分位点でデータを層別化
   → 「一般変数で予測しやすいグループ」と「予測しにくいグループ」を分離
```

- **解釈**：予後スコア（Prognostic Score）と本質的に同じ概念

#### 方法2B：予測残差の絶対値ベース
```
手順:
1. 同上のモデルから予測確率 p_hat を得る
2. 残差 r = Y - p_hat を算出
3. |r| の大きさで層別化
   → 残差大群 = X では説明できない要因の影響が強い群
```

- **利点**：直観的にわかりやすい；「未説明部分」を直接的に切り出す
- **懸念**：二値アウトカムの残差分布が歪む；Y=1かつp_hat≈0のサンプルと、Y=0かつp_hat≈1のサンプルは質的に異なる可能性

#### 方法2C：交差検証型決定力スコア
```
手順:
1. データをK-fold に分割
2. 各foldについて、残りのfoldでモデルを学習し、holdout foldの予測確率を得る
3. 交差検証予測確率を「決定力スコア」として使用
4. 層別化に用いる
```

- **利点**：過学習の回避（パイロットデザインの思想と共通; Aikens et al., 2020）
- **懸念**：計算コスト増

#### 方法2D：機械学習モデルの不確実性ベース
```
手順:
1. X1〜X10 を入力としたRF / GBM / ニューラルネットでYを予測
2. モデル不確実性（RF: tree間の分散、NN: MCドロップアウトの分散）を算出
3. 不確実性の大きさで層別化
```

- **利点**：非線形な予測力の「行き詰まり」を捕捉
- **懸念**：モデルの不確実性 ≠ 入力変数の情報不足（アレアトリック vs エピステミック）の区別が必要

### 4.3 傾向スコア系手法との位置づけの違い

```
┌────────────────────────────────────────────────────────────┐
│                 本研究の手法2                                 │
│  一般変数 X ──→ Y の予測力で層別化                           │
│  （予後スコア型、ただし「重大変数を意図的に除外」した状態）     │
│                                                              │
│  vs.                                                         │
│                                                              │
│  傾向スコア法                                                 │
│  共変量 ──→ 治療割り付け確率で層別化                          │
│  （因果推論の文脈で治療効果の偏りなき推定が目的）              │
│                                                              │
│  vs.                                                         │
│                                                              │
│  予後スコア法（Stuart et al., 2013; Aikens et al., 2020）     │
│  共変量 ──→ アウトカム予測確率で層別化                        │
│  （全共変量を使用する前提）                                    │
└────────────────────────────────────────────────────────────┘
```

**本研究のユニークさ**：意図的に重大変数Zを除外した上で X→Y 予測を行い、その「限界」から Z の存在を逆推定しようとする点。

## 5. 検証3：未測定重大変数のあぶり出し能力の評価

### 5.1 評価の枠組み

シミュレーションでは Z の真値が既知であるため、以下の問いを定量的に評価できる：

> **手法1・2で作成された「層（stratum）」は、Z によって定義される「真のクラスタ」とどの程度一致するか？**

### 5.2 真のクラスタの定義

重大変数 Z から真のクラスタを以下のように定義する：

| クラスタリング方法 | 詳細 |
|-------------------|------|
| **離散化クラスタ** | Z1(年齢) を3区分 × Z2(性別) 2区分 × Z3(BMI) 3区分 = 最大18クラスタ |
| **Z空間クラスタリング** | Z1, Z2, Z3 の標準化空間で k-means（k を真クラスタ数に合わせる） |
| **Z由来の予後リスク層** | Z のみからアウトカムを予測した予測確率の分位点による層 |

### 5.3 一致度の評価指標

#### (a) クラスタ一致度指標

| 指標 | 説明 | 適用場面 |
|------|------|----------|
| **Adjusted Rand Index (ARI)** | 偶然一致を補正したクラスタ一致度。[-1, 1]、1で完全一致 | クラスタ vs 層 |
| **Normalized Mutual Information (NMI)** | 情報理論ベースのクラスタ一致度。[0, 1] | クラスタ vs 層 |
| **V-measure** | 均質性(Homogeneity)と完全性(Completeness)の調和平均 | クラスタ vs 層 |

#### (b) 層内 Z 分布の均質性

| 指標 | 説明 |
|------|------|
| **層内 Z の分散比（ANOVA的）** | 層間分散 / 全分散。大きいほど層がZの情報を捕捉 |
| **層内 Z2(性別) のエントロピー** | 各層内の性別比が偏っているほどエントロピーが低い（= 層が性別を捕捉） |
| **η²（イータ二乗）** | 層を群変数、Zを従属変数としたときの効果量 |

#### (c) シンプソンのパラドックス解消度

| 指標 | 説明 |
|------|------|
| **方向一致率** | 全体効果とすべての層内効果の方向（正/負）が一致する割合 |
| **Cochran-Mantel-Haenszel検定** | 層別調整後の共通オッズ比と、未調整オッズ比の乖離 |

### 5.4 感度分析パラメータ

以下を変化させて手法の頑健性を評価：

| パラメータ | 変動範囲 | 目的 |
|------------|----------|------|
| Zの効果サイズ | OR 1.2〜5.0 | 重大変数の影響度に対する感度 |
| Z→X の影響経路の強さ | 相関 0.1〜0.7 | 間接的痕跡の濃さへの感度 |
| X→Y の直接効果の大きさ | OR 1.0〜2.0 | 一般変数自体の予測力への感度 |
| ノイズレベル | 低/中/高 | 偶然変動への頑健性 |
| Zの変数数 | 1, 2, 3 | 未測定変数の複雑さへの感度 |

## 6. 検証4：疑似ランダム化の妥当性評価

### 6.1 「疑似ランダム化」の操作的定義

本研究における「疑似ランダム化が成立する」とは、以下を意味する：

> **手法1・2による層別化の後、各層内において Z の分布が（近似的に）均一化され、あたかもランダムに Z が割り当てられたかのような状態になること**

### 6.2 評価基準

#### (a) 共変量バランス指標（層内）

| 指標 | 説明 | 閾値の目安 |
|------|------|------------|
| **標準化平均差（SMD）** | 層内の Z の各水準間での共変量バランス | |SMD| < 0.1 で良好 |
| **分散比（Variance Ratio）** | 層内サブグループ間の分散の比 | 0.5〜2.0 の範囲で許容 |
| **KS統計量** | 連続変数の分布の全体的な類似度 | p > 0.05 |

#### (b) 因果効果推定の偏り

真の因果効果が既知（シミュレーション）であることを活かし：

| 指標 | 説明 |
|------|------|
| **バイアス** | E[θ_hat] - θ_true |
| **RMSE** | √(バイアス² + 分散) |
| **カバレッジ率** | 95%CIが真値を含む割合 |
| **シンプソンパラドックス発生率** | 層別後にパラドックスが解消される割合 |

#### (c) ベースライン手法との比較

本手法の妥当性を評価するために、以下のベースラインと比較する：

| 比較手法 | 説明 |
|----------|------|
| **無調整（Crude）** | 層別化なしの粗分析 |
| **真のZによる層別化（Oracle）** | Zを直接知っている場合の層別化（理論上の上限） |
| **傾向スコア層別化（PS）** | X を用いた傾向スコア（治療モデル型） |
| **完全な予後スコア層別化** | X + Z すべてを用いた予後スコア（実際は不可能だが上限として） |
| **ランダム層別化** | データをランダムに層に分割（下限ベースライン） |

#### (d) 偶然変動への対処の評価

| 評価項目 | 方法 |
|----------|------|
| **ブートストラップ安定性** | 1000回のブートストラップで層帰属の安定性を評価 |
| **層別化結果の再現性** | 異なるランダムシードで層割り当てがどの程度変動するか |
| **小サブグループの影響** | 層内サンプルサイズが小さい場合の推定量の分散増大を評価 |

## 8. 理論的考察（ブレインストーミング段階のメモ）

### 8.1 この手法が機能する条件（予想）

1. **Z→X の影響が十分に強い場合**：Z の「痕跡」がXの多変量空間に残るため、層別化がZのクラスタと一致しやすい
2. **X の次元がZの次元より十分に大きい場合**：10次元のXから2〜3次元のZを逆推定するのは、自由度の観点から原理的に可能
3. **Zの効果が線形的に X に反映される場合**：PCAベースの手法が特に有効と予想
4. **Z間に交互作用がある場合**：非線形手法（AE、RF）が線形手法を上回ると予想

### 8.2 この手法が失敗する条件（予想）

1. **Z→X の影響が弱い場合**：Xの空間にZの情報がほぼ残らない
2. **X→Y の直接効果が支配的な場合**：手法2（決定力ベース）の残差にZの情報が含まれなくなる
3. **複数のZが相互に相殺する影響を持つ場合**：PCA等の線形手法では分離できない
4. **サンプルサイズが小さい場合**：偶然変動が層別化の精度を圧倒する

### 8.3 傾向スコア法との理論的関係

- **傾向スコア法**は「治療の割り付け確率」でバランシングする ← **背景変数から治療方向** へ向かう矢印をモデル化
- **手法2（決定力ベース）**は「アウトカムへの予測力」で層別化する ← **背景変数からアウトカム方向** へ向かう矢印をモデル化
- **手法1（特徴量得点ベース）**は背景変数間の相互関係自体で層別化する ← **因果構造から独立** な、純粋にデータ駆動型のアプローチ

手法1は因果推論の枠組みでは「無情報な層別化」と見做される可能性があるが、Zの痕跡がXに残るなら有効。これは **「近接因果推論（Proximal Causal Inference）」** の概念に関連する可能性がある（Xがunmeasured Zのproxy）。

### 8.4 偶然変動への対処の方針

| 戦略 | 内容 |
|------|------|
| **正則化** | 特徴量得点算出時にリッジ/LASSO正則化 |
| **クロスバリデーション** | 層別化スコアの算出にCV型パイロットデザインを採用 |
| **ブートストラップ集約** | 複数回の層別化結果を集約（Bagging of stratification） |
| **層の最小サンプルサイズ制約** | 各層に最低n人を確保する制約条件 |
| **ペナルティ付きクラスタリング** | 極端に小さいクラスタを抑制 |

## Appendix B: Glossary

| Terms | Definitions |
|------|------|
| Confounder | Variables that causally influence both exposure and outcome |
| Simpson's Paradox | A statistical phenomenon in which the overall association is reversed in subgroups |
| Propensity Score | Probability of treatment assignment given observed covariates |
| Prognostic Score | Predictive value of predicting outcome from covariates |
| Disease Risk Score (DRS) | Outcome prediction score estimated from unexposed group only |
| Proximal Causal Inference | Causal inference framework using proxy variables for unmeasured confounding |
| ARI (Adjusted Rand Index) | Cluster concordance index corrected for coincidence |
| NMI (Normalized Mutual Information) | Information theory-based cluster concordance index |
| DAG (Directed Acyclic Graph) | Directed acyclic graph that expresses causal structure |
