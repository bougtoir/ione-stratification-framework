# 予後スコア（Prognostic Score）と高次元傾向スコア（hdPS）の詳細解説

---

## 1. 予後スコア（Prognostic Score）

### 1.1 定義

予後スコアとは、**共変量からアウトカム（結果変数）を予測した予測値**のことです。

```
傾向スコア（PS）: P(治療=1 | 共変量X)    ← 「治療を受ける確率」
予後スコア    : E(Y | 共変量X, 治療=0)   ← 「治療を受けなかった場合のアウトカム予測値」
```

Hansen (2008) が「傾向スコアの予後的アナログ（The prognostic analogue of the propensity score）」として *Biometrika* で提唱しました。

### 1.2 傾向スコアとの対比

| 側面 | 傾向スコア (PS) | 予後スコア |
|------|----------------|-----------|
| **モデルの目的変数** | 治療割り付け（曝露） | アウトカム（結果） |
| **モデルの説明変数** | 共変量 X | 共変量 X |
| **学習データ** | 全サンプル | **対照群（非曝露群）のみ** |
| **捕捉する情報** | 「なぜその治療を受けたか」 | 「治療を受けなければどうなっていたか」 |
| **バランシングの性質** | 共変量の分布を群間で均等化 | **アウトカムに関連する変動**を群間で均等化 |
| **理論的保証** | 強い無視可能性の下で無偏推定 | 同条件で無偏推定 + 精度向上の可能性 |

### 1.3 なぜ予後スコアが注目されるのか

#### (a) 精度（Precision）の向上

傾向スコアは「治療割り付けに関連する変数」でバランスを取りますが、アウトカムとの関連が弱い変数も含んでしまうことがあります。一方、予後スコアはアウトカムとの関連が強い変数に自然に重みを置くため、**推定量の分散が小さくなる**傾向があります。

```
例）
  - 変数A: 治療割り付けに強く関連、アウトカムに無関連
  - 変数B: 治療割り付けに弱く関連、アウトカムに強く関連

  PS: 変数Aに大きな重み → アウトカム予測には寄与しない変数でバランスを取る → 無駄
  予後スコア: 変数Bに大きな重み → アウトカムの変動を直接減らす → 効率的
```

#### (b) 未測定交絡への感度分析の改善

Aikens et al. (2020) が示した重要な知見：

> 予後スコアで層別化すると、**層内の残差分散が小さくなる**ため、仮に未測定交絡が存在しても、その影響が検出されやすくなる（感度分析のパワーが向上する）。

直感的には：
- 予後スコアで層別化 → 各層内でアウトカムの変動が小さくなる
- 小さい変動の中で治療効果を検出 → 信号/ノイズ比の向上
- 未測定交絡の影響も「小さい変動の中での異常」として現れやすくなる

#### (c) 傾向スコアの誤特定に対する頑健性

傾向スコアモデルが誤って指定された（例えば非線形項や交互作用項が欠落した）場合でも、予後スコアで層別化していれば、推定の偏りがある程度抑えられることが示されています（Leacy & Stuart, 2014; Antonelli et al., 2018）。

### 1.4 パイロットデザイン

予後スコアの実用上の最大の問題は**過学習**です。アウトカム Y を使ってモデルを構築し、同じデータで効果推定を行うと、バイアスが生じます。

Aikens et al. (2020) が提唱した**パイロットデザイン**はこれを解決します：

```
┌─────────────────────────────────────────────────────┐
│ 全データ                                              │
│                                                       │
│  ┌──────────────────┐  ┌──────────────────────────┐  │
│  │  パイロットセット   │  │  分析セット                │  │
│  │  （対照群の一部）    │  │  （残りの全サンプル）       │  │
│  │                    │  │                          │  │
│  │  ① ここでYを使って │  │  ③ パイロットで学習した    │  │
│  │    予後モデルを     │  │    モデルで予後スコアを    │  │
│  │    学習する         │  │    算出                   │  │
│  │                    │  │                          │  │
│  │  ② Yの情報を       │  │  ④ 予後スコアで層別化     │  │
│  │    「消費」する     │  │    → マッチング → 解析    │  │
│  │                    │  │                          │  │
│  │  ※ 分析には使わない │  │  ※ Yを見ずに設計完了     │  │
│  └──────────────────┘  └──────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

**ポイント**：パイロットセットのサンプルは分析から除外されるため、「Yの情報を設計に使ったのに、同じYで効果を推定する」という循環論法を回避できます。

### 1.5 予後スコアの限界

1. **単独では交絡調整の理論的保証がない**：傾向スコアとは異なり、予後スコアだけでの層別化では、交絡の完全な調整が保証されません。傾向スコアとの**併用**（予後スコアで層別化 → 層内で傾向スコアマッチング）が推奨されます。
2. **パイロットセットにデータを「消費」する**：分析に使えるサンプルが減ります（ただし大規模データでは問題になりにくい）。
3. **予後モデルの精度に依存**：アウトカム予測モデルが不正確だと、層別化の効果が減衰します。

## 2. 高次元傾向スコア（High-Dimensional Propensity Score; hdPS）

### 2.1 定義と動機

Schneeweiss et al. (2009) が *Epidemiology* で提唱。

**問題**：レセプトデータ（保険請求データ）等を用いた薬剤疫学研究では、BMI・喫煙状態・検査値などの臨床的に重要な交絡変数が直接測定されていないことが多い。

**着眼点**：しかし、データベースには診断コード・処置コード・処方コードなどが**大量に**記録されている。これらは個々には不完全だが、**集合的に**未測定交絡の代理指標（proxy）として機能しうる。

```
例）喫煙状態は直接記録されていないが…
  - 「ニコチンパッチの処方」
  - 「COPD（慢性閉塞性肺疾患）の診断コード」
  - 「呼吸器科の受診」
  - 「肺がん検診の手続き」
  → これらを組み合わせれば、「この患者はおそらく喫煙者」と推定できる
```

### 2.2 アルゴリズムの7ステップ

```
┌─────────────────────────────────────────────────────────────────┐
│                    hdPS アルゴリズム                               │
│                                                                   │
│  Step 1: データ次元の特定                                         │
│  ─────────────────────────────                                    │
│  レセプトデータの「次元」を定義する                                 │
│  例）診断コード(ICD)、処置コード(CPT)、薬剤コード(NDC)、          │
│     検査コード、入院情報 等                                        │
│                                                                   │
│  Step 2: 候補共変量の経験的特定                                    │
│  ───────────────────────────────                                   │
│  各次元から出現頻度の高いコードを抽出                               │
│  例）各次元から上位200コードずつ                                    │
│  → 5次元 × 200 = 1,000 候補共変量                                │
│                                                                   │
│  Step 3: 再発性の評価                                              │
│  ──────────────────                                                │
│  各コードについて「1回でも出現」「散発的」「頻回」の3変数に展開     │
│  → 1,000 × 3 = 3,000 の二値変数候補                              │
│                                                                   │
│  Step 4: 共変量の優先順位付け                                      │
│  ─────────────────────────────                                     │
│  各候補共変量について「バイアス誘発ポテンシャル」を算出              │
│                                                                   │
│  Bhat = |log(RR_cd)| × |P(cov|exposed) - P(cov|unexposed)|       │
│                                                                   │
│  RR_cd : その共変量とアウトカムの粗関連                             │
│  P差分 : その共変量の曝露群・非曝露群間の有病率差                   │
│                                                                   │
│  → Bhat が大きい共変量 = 交絡を引き起こしている可能性が高い         │
│                                                                   │
│  Step 5: 共変量の選択                                              │
│  ──────────────────                                                │
│  Bhat の上位 k 個（通常 k=500）を選択                              │
│  + 研究者が事前に定義した重要共変量（年齢・性別等）                  │
│                                                                   │
│  Step 6: 傾向スコアの推定                                          │
│  ──────────────────────                                            │
│  選択された共変量（500+α個）を説明変数として                        │
│  ロジスティック回帰で傾向スコアを推定                               │
│                                                                   │
│  Step 7: アウトカムモデルの推定                                     │
│  ───────────────────────────                                       │
│  傾向スコアの層別化（通常10分位）内での効果推定                     │
│  または傾向スコアマッチング → 条件付き効果推定                      │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 「代理変数の連鎖」という概念

hdPS の理論的基盤は**「代理変数の連鎖（chains of proxies）」**という考え方です：

```
真の交絡変数     レセプト上の記録        hdPSが捕捉するもの
─────────────   ──────────────────     ────────────────────
                  処方記録 ←──────┐
患者の健康状態 → 医師の診断 → 診断コード ──┤→ 集合的な代理指標
                  検査オーダー ←──┘    （proxy）
                  入院記録 ←──────┘

例）
「フレイル（虚弱）」  →  杖の処方 + 転倒の診断 + 自宅訪問看護 + 複数薬剤処方
  （直接測定不可）       → これらの組合せが「フレイル」のproxyになる
```

### 2.4 有効性の実証例

Schneeweiss et al. (2009) の原著論文での検証：

| 研究 | 粗RR | PS(15変数) | hdPS(+500変数) | RCTの結果 |
|------|------|-----------|----------------|----------|
| COX-2阻害薬 vs NSAID → 上部消化管毒性 | 1.09 | 0.94 | **0.88** | ~0.5-0.6（胃保護効果あり） |
| スタチン → 死亡率低下 | 改善 | 改善 | **さらに改善** | 効果あり |
| インフルエンザワクチン → 股関節骨折（陰性対照） | - | - | **1.02（null確認）** | 関連なし（期待通り） |

**注目すべき点**：15変数の従来型PSでは不十分だった調整が、hdPS（+500変数）で改善され、RCT（ランダム化比較試験）の結果に近づいています。特に**陰性対照研究**（インフルエンザワクチン→骨折：因果関係がないことが明らかな組み合わせ）でnull結果を確認できた点が、hdPSの妥当性を裏付けています。

### 2.5 Step 4（優先順位付け）の数学的詳細

hdPSの核心はStep 4のバイアス誘発ポテンシャル Bhat の計算です：

```
各候補共変量 c について：

1. アウトカムとの関連: RR_cd = P(Y=1|c=1) / P(Y=1|c=0)

2. 曝露との関連: ΔP = P(c=1|曝露群) - P(c=1|非曝露群)

3. バイアス誘発ポテンシャル:
   Bhat_c = |log(RR_cd)| × |ΔP|

   → 「アウトカムにも曝露にも関連する変数」= 交絡変数の定義そのもの
   → Bhat が大きい変数を優先的に傾向スコアモデルに投入する
```

この式は**交絡変数の操作的定義**（曝露とアウトカムの両方に関連する変数）を直接数値化したものです。

### 2.6 hdPS の限界と注意点

| 限界 | 詳細 |
|------|------|
| **未測定交絡の完全な解消は不可能** | 代理変数はあくまで proxy であり、真の交絡変数そのものではない。調整は「改善」されるが「完全」にはならない |
| **データ次元に依存** | レセプトデータが貧弱（コードの種類が少ない）なら、proxyの質も低い |
| **計算コスト** | 数千の候補変数の評価が必要。大規模データでは計算時間が問題になりうる |
| **変数選択のバイアス** | Step 4 の優先順位付けで、曝露ともアウトカムとも弱い関連しかない真の交絡変数が除外されるリスク |
| **過適合のリスク** | 500変数をロジスティック回帰に投入 → PS推定の分散が大きくなる可能性。正則化や機械学習の導入が検討されている（Wyss et al., 2022） |
| **操作変数や衝突変数の混入** | アルゴリズム的に選択された変数が、調整すべきでない変数（collider等）である可能性 |

## 3. 予後スコアと hdPS の関係・併用可能性

### 3.1 二つのアプローチの位置づけ

```
                     モデルの方向性
              ────────────────────────────
              共変量 → 治療      共変量 → アウトカム
              (Treatment model)  (Outcome model)
              ─────────────────  ──────────────────
少数の        │  従来のPS       │  予後スコア      │
事前定義変数  │  (Rosenbaum     │  (Hansen 2008)   │
              │   & Rubin 1983) │                  │
              ─────────────────  ──────────────────
大量の        │  hdPS           │  高次元          │
経験的選択変数│  (Schneeweiss   │  予後スコア      │
              │   et al. 2009)  │  (未開拓領域)    │
              ─────────────────  ──────────────────
```

### 3.2 本研究との関連

仕様書で提案している手法は、上図の**右下象限**（高次元予後スコア）に近い概念を、さらに発展させたものと位置づけられます：

| 本研究の手法 | 既存手法との対応 |
|-------------|----------------|
| **手法1（特徴量得点ベース）** | 予後スコアの「教師なし版」。Yの情報を使わず、Xの多変量パターンだけで層別化 |
| **手法2（決定力ベース）** | 予後スコアに最も近い。ただし「重大変数を意図的に除外」した上でYを予測する点が独自 |

### 3.3 Kabata et al. (2024) による最新の統合アプローチ

最近の研究（BMC Medical Research Methodology）では、**予後スコアベースのモデル平均化**による傾向スコア推定が提案されています。予後スコアによる共変量バランスを基準として最適な傾向スコアモデルを選択するアプローチで、両者の長所を統合しようとする試みです。

## 4. まとめ：両手法の核心

| | 予後スコア | hdPS |
|---|---|---|
| **一言で** | 「この患者は治療しなくてもどうなるか」の予測値 | 「大量の代理変数で交絡を経験的に調整する」アルゴリズム |
| **発想の起点** | アウトカム側の変動を制御 → 精度向上・感度分析強化 | 測定変数が不完全 → 大量のproxyで補完 |
| **未測定交絡への態度** | 直接は対処しないが、感度分析のパワーを高める | 間接的に対処（proxyの集合体で近似） |
| **本研究への示唆** | 手法2の理論的基盤；パイロットデザインの採用を検討すべき | 「大量のXからZの痕跡を捕捉する」という発想が本研究の手法1と共通 |
